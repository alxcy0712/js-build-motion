# 统一视频封面模板

暖白底 `#F7F5EF`、黑色标题 `#24231F`、固定强调色 `#FFC712`。AI 生成单主体插画，JS Canvas 精确合成标题、强调色与右下角头像。

| 画幅 | 导出尺寸 | 布局 |
|---|---|---|
| 竖版 3:4 | 1080 × 1440 | 栏目、标题和主体沿同一左侧网格排布，右下角头像 |
| 横版 4:3 | 1440 × 1080 | 左侧标题与右侧主体垂直居中对齐，右下角头像 |

`examples/portrait.png` 与 `examples/landscape.png` 是可直接使用的示例；`index.html` 提供双画幅预览、栏目下拉选择、修改标题、替换或删除主题图、选择头像表情、调整头像大小和 PNG 导出。栏目包含 AI 创作、AI 工具、编程开发、创作技巧和隐藏栏目。标题保持一到两行，每行建议 3–6 个字。字体采用系统苹方，依次回退到冬青黑体、微软雅黑与系统无衬线。

图文布局采用大标题、紧凑行距和黄色栏目标签。主题图保持原比例并收在圆角区域内。点击“删除主题图”后，两版标题块在画面中央排布，行内文字保持左对齐；重新上传图片恢复图文布局。

“头像表情”保留默认头像，并从个人 IP 的 `expressions.json` 动态读取 18 种表情，包括新增的生气、难过、落泪、怀疑、释然、兴奋。“头像朝向”支持正面、左 45°、右 45°，左右以画面方向为准；默认头像的左右版本使用对应的平静微笑。“头像大小”滑块支持 50%–150%，默认 100% 对应 204 × 204 像素。大小、表情与朝向同步更新两种画幅和导出结果，缩放时距右侧和底部均保持 96 像素。“恢复示例”同时恢复标题、主题图、正面默认头像和 100% 大小。

## 布局优化规则

| 优化点 | 当前规则与用途 |
|---|---|
| 个人 IP 更清晰 | 两版头像默认占位为 204 × 204，可用同一个滑块调整为 102–306 像素；距右侧与底部均为 96 像素。 |
| 标题优先 | 图文版标题最大字号为竖版 160、横版 164，纯文字版为 176；长标题按可用宽度自动缩小。 |
| 信息层级更明确 | 栏目采用黑字、#FFC712 标签；标题仅使用黑字。黄色装饰集中到栏目与 AI 主体。隐藏栏目时保留简洁文字构图。 |
| 对齐更精确 | 用实际字形边界计算标题宽度、居中与逐行左对齐；行距统一为字号的 1.2 倍。 |
| 图文关系更紧密 | 竖版主题图与标题共用 96 像素左边距，距标题末行下沿 80 像素；横版标题与主题图共用垂直中心。 |
| 留白更稳定 | 主题图保持原比例，默认排版保留主体与头像之间的间隔，四周留白稳定。 |

视觉参考的出处与贡献集中记录在根 README.md 的致谢表中；本目录保存可独立复用的排版规则、素材与代码。

## 每次发布

1. 写出一个明确的短标题，选择与本期内容对应的单个主体。
2. 用 `image-prompt.txt` 生图；复用透明背景、圆润 3D 材质、暖白与 `#FFC712` 配色，保留主体四周余量。
3. 在编辑页填写标题，选择主题图、头像表情与大小；纯文字封面点击“删除主题图”。检查两版预览并分别导出 PNG。

从仓库根目录启动资产编辑页，服务直接读取共享的个人 IP 源素材：

```bash
node assets/douyin-cover/preview.mjs
```

打开终端返回的本地网址。命令行可追加端口，如 `preview.mjs 8822`。AI 主题图保存在本目录 `images/`；个人 IP 统一读取同一仓库的 `assets/personal-ip/`，通过 `/personal-ip/` 路由提供给编辑页。项目副本沿用该共享来源。

`template.js` 暴露 `DouyinCover.draw(canvas, { format, kicker, lines, hero, avatar, avatarScale })`，`format` 为 `portrait` 或 `landscape`；两版使用同一个渲染函数。`hero` 与 `avatar` 为已加载的图片对象；`avatarScale` 默认为 1，编辑页范围为 0.5–1.5；省略 `hero` 使用居中的纯文字布局。

AI 主体使用内置 imagegen 生成并修订；固定图片可以重复排版，新的生图结果具有生成变化。可复用提示词见 `image-prompt.txt`，示例的完整生成及修订提示词见 `example-prompts.json`，来源与文件哈希见 `manifest.json`。默认正面头像直接读取 `assets/personal-ip/portrait.png`；18 种表情及其三个朝向按 `assets/personal-ip/expressions.json` 中的路径读取，共享路由为 `/personal-ip/`。该目录是头像的唯一维护位置；更新源素材后刷新编辑页即可使用。
