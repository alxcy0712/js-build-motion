# 视频创作方法研究

本目录积累可迁移的理念、假设与研究方法，按能力组织知识。执行规范、组件和测试由 [.skill](../.skill/SKILL.md) 维护；目录边界与知识提炼规则见[核心维护](../.skill/references/maintenance.md)。

## 核心理念

影片通过连续变化组织注意力。每个镜头建立一个状态，让观众追踪变化，并在结果中获得新的理解或感受。构图、运动、文字与声音共同服务这一过程。

## 研究方法

1. **提出可迁移问题**：用观众感知或工具行为描述缺口，明确适用条件与反例。
2. **区分证据层级**：文字支持作者陈述，静帧支持构图和形状，连续观看支持运动与节奏，试听支持声音判断。每项结论与实际证据范围对应。
3. **提炼机制**：写清状态、触发、变化与结果。风格、时长、帧率、响度和评分按目标调整。
4. **独立验证**：公式与代码使用独立计算或行为检查；视觉假设使用完整动态粗剪和代表性样片；传播假设使用发布后的实际数据。
5. **吸收与收敛**：将“问题 → 原理 → 条件 → 方法 → 验证”写入对应主题，执行细节链接到唯一权威文件。合并同义规则，保留有效边界与来源，替换过期结论。

可分享的知识使用虚构对象与通用变量说明机制。具体项目的名称、用户原文、文件身份、素材、观察日志、审片结论与待办保存在项目证据中；跨项目维护过程保存在本地维护归档中，位置由[维护规范](../.skill/references/maintenance.md)约定。
