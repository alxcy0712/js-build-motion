# 竖屏构图与画幅利用

适用于 Grok Bot 团队与 Codex 等本地 Agent 的竖屏制作、改片与画面复盘。规划时与[导演计划](direction.md)一起读取，实现时配合[绘制](drawing.md)，审片时配合[成片质量](quality.md)。让实景充分使用竖屏空间、主体有足够尺度，留白承担明确的表达用途；本片已确认的风格、事实、音源与审批继续沿用。素材访问、配音和执行环境按根 AGENTS.md 的角色分工处理。

## 先区分位置、尺度和版式

先从当前交付记录找到实际 MP4，登记哈希、画幅、帧率与取样时间。已有影片的衍生剪辑按当前交付入口读取；源码、历史帧与当前编码分别标明。检查编码宽高、像素宽高比和旋转信息，再在原比例完整画幅内观察；播放器窗口与编码画面分别定位。

| 现象 | 核对依据 | 对应操作 |
|---|---|---|
| 主体持续偏向一角 | 主体与关系图的实际外框、预期焦点、素材自身空边、相机变换；同时看高亮与大字的视觉重量 | 修正主体锚点、素材裁框或相机焦点，重排相关标签 |
| 已居中，画面仍显小 | 主体宽高占比、照片窗口占比、四周空带及其用途 | 放大主体或更换取景，按镜头重新安排图文关系 |
| 连续多镜像同一页 | 全片联系表中的标题带、中央窗口、来源行与景别分布 | 按内容改为环境全貌、对象近景、局部解释或结果停留，保留同一识别体系 |

平移改变位置，缩放改变尺度，重构图改变信息的空间关系。对多种镜头分别选择操作，并复核字幕、来源和相邻切点。

## 分开三层坐标

| 图层 | 设计范围 | 检查重点 |
|---|---|---|
| 场景／环境 | 以整个编码画布铺设实景、环境或有意义的图形空间；推拉过程也覆盖画幅 | 实景的边缘连续、缩放后的露底、源素材内嵌黑边 |
| 主体／关系 | 根据本镜意义选择全貌或局部，以完整画布的预期焦点组织尺度 | 对象、必要地标、动作空间、关系完整性与光学重心 |
| 文字／字幕／来源 | 在平台界面避让区内安排必要信息，字幕保留自己的稳定位置 | 字形边缘、对比、读时，平台按钮和字幕对关键证据的遮挡 |

`SAFE_AREA` 与 `VERTICAL_SHORT_LAYOUT` 的权威值在固定运行时的 `src/themes/shared.ts`，用于必要信息的避让与布局起点。左右、上下边距有意不同，安全矩形中心会偏离画布中心。全画幅背景按画布铺设，主体按镜头焦点定位，必要标签按安全区避让。沿用既有 token 与引擎契约，布局调整在本片 `src/` 完成。

在同一逻辑画幅内计算主体锚点，再统一映射到编码或预览尺寸。以 1080×1920 为例，画布中心为 (540, 960)；实际焦点可因视线、动作或证据避让而偏移，记录用途。把照片窗口、对象外框、标题与字幕分别画出辅助框，核对其屏幕位置。单个字形的越界检查覆盖裁切风险；全片联系表与当前编码取样覆盖构图判断。

主体、连接线与世界标签共用相机变换；屏幕字幕、来源与固定信息各自排版。`save/restore` 分离图层变换。源图自带留白或透明边时，依据可见对象外框定位；全局平移只用于已证实的共同坐标错误。

## 按镜头决定占幅

- **实景与环境镜头**：从全画幅取景起步，把必要短标题或标注叠在场景上，通过局部底板或渐变维持对比。检查人物、招牌和当前证据的裁切；横图承担完整关系或证据时保留其完整视图，再安排背景与解释空间。
- **主体与机制图解**：按需要看清的关系放大主体，允许环境、路径与次要轮廓延伸至边缘。长过程先建立全貌，再推近当前动作，最后回到完整结果。固定比较尺度、单位和对象身份；标签及关键连接点保持可读。
- **截图、对照与数据**：完整性优先，适合 `contain` 或局部放大加位置线索。比较对象保持共同尺度；镜头空间由本次证据决定。
- **提问、停顿与结论**：纯色背景和大面积留白可用于集中注意。明确主词／对象、尺度和停留用途，与前后镜头形成强弱变化。

图片的 `cover` 只保证覆盖传入的目标矩形。需要全画幅时，目标框使用整个画布；裁切前检查源图中的关键对象，并按裁后有效像素核对原尺寸清晰度。裁后细节不足时缩小取景放大幅度，或按既有素材授权补充更合适的原件。`contain` 用于完整展示；保留源比例。需要时按[绘制入口](drawing.md)复制 `image-fit` 组件，使用现有 `fitImage`。相机推拉与素材适配各指定一个控制位置，复核最终叠加尺度。

将页眉、标题、资料窗口和来源按其信息用途出现。用[镜头编排](direction.md)比较相邻镜头：实景提供空间，近景给细节，图解解释关系，简洁镜头承接停顿。`minimal` 可以采用铺满的实景与大尺度主体，动作强度继续遵循已选主题。

## 以同内容对照验证

已有片反馈“偏移／未铺满”时，从已定位问题中选有代表性的实景、图解与留白镜头；新片把这项比较纳入既有粗剪。保留相同内容、时间点和观看尺寸，对照位置调整与尺度／构图调整的结果。试排与正式采用分别记录，沿用本片的视觉审批约定。

在现有 `events.md`／`review.md` 中记录：时间码、镜头任务、主体外框、焦点、留白用途、修正与编码复核。外框先按照片窗口或可见主体定义口径，再计算 `宽/W`、`高/H` 与中心 `(x+w/2, y+h/2)`；背景覆盖、窗口占幅和主体占幅分别记录。几何中心辅助定位，视觉重心同时看对比、亮度、文字和运动。全画幅暗场与单色图解按其内容判断，像素亮度统计仅作定位线索。

占幅的具体数值由题材、素材裁切、平台遮挡和阅读任务决定。跨镜比较能暴露反复偏移、相同小窗口及无明确用途的空带；检查重点是主对象与证据能否被看清、镜头空间是否服务当前内容。

验收复用三种已有观察：

1. 全片联系表：保留完整 9:16 边界和时间码，检查主体位置、上下空带与连续镜头的尺度变化。
2. 360px 宽预览与平台界面遮挡示意：对照干净画面核对主体、关键地标、标签及字幕。示意区标明依据，实际发布界面可用时按其复核。
3. 运动极值、切点两侧连续帧与正常速度片段：检查推近后的裁切、移动时的露底、焦点跳动和阅读窗口。分别记录实际完成范围。

退出条件是对应问题有新编码或试排证据，关键事实和标签完整，手机尺度可读，留白与景别有明确作用。单次构图对照支持该条件下的改进；完整叙事、声音与受众理解继续按各自观察范围评价。维护证据、参考身份和具体项目数据按[核心维护](maintenance.md)保存在本地项目。
