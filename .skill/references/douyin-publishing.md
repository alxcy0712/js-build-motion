# 抖音口播稿、合规与发布

适用条件：发布到抖音的口播/解说视频。口播稿、字幕、屏幕大字、标题简介与封面都按本文检查；画面版面见[竖屏版面默认](styles.md#竖屏-916-口播版面默认)，分镜见[按 TTS 时间戳拆分镜](captions-and-shots.md#按-tts-时间戳拆分镜)。需要独立封面时，由宿主 Agent 读取仓库根 `assets/douyin-cover/README.md` 的“出图补充规则”，按其要求把选用模板与素材复制到本片后执行；本片 guide/ 保存制作规范快照。

本清单与角色专用约定一起读取；本人形象、配音、品牌原件和本地剪辑的专用约定按根 AGENTS.md 对应角色执行。具体发布要求按本片采用范围核验并留存来源。

## 口播稿写法

- 说人话：像跟朋友聊天，句子短，能念出口。
- 单位默认用中国常见写法（公里、公里每小时等），不用英里、mph；换算要准，别为了顺口硬凑丢精度（例如 60 mph 写成约 96 公里每小时，不要硬改成「百公里」）。
- 技术比喻一条稿子最多一两个，并落到具体的事上。
- 不用模板句：「本质上」「不是…而是…」「破局」「底层逻辑」这类说法都不用。
- 写真实经历：优先用作者本人的做法和感受，不编造经历、数据或引语。
- 默认结构：开头三秒抛出一个具体的反常识或场景 → 中间分点讲清机制 → 讲代价 → 讲办法 → 收尾（见下条）。结尾不收金句，用自己的真实做法或一句落地的话结束。题材不适合时按[创作问答](intake.md)调整并记录理由。
- 收尾口播跟随片尾卡：每片询问用户是否采用片尾头像与个人 IP 落款（见[创作问答](intake.md#片尾头像与个人-ip-落款)）。用户确认采用时，口播以『我是澄记，用计算机思维想现实。』结尾，前一句要跟全片内容自然接上，不能硬贴，片尾卡按口播实测时间同步，规格见[片尾头像与个人 IP 落款](visual-identity.md#片尾头像与个人-ip-落款)。用户不采用时不念这句，口播在正片内容的结论处结束。主账号与 5W1H 账号、团队制作与本地剪辑都按此执行。
- 去 AI 味：成稿后用 humanizer-zh 或 dbs-ai-check（当前环境可用时）自查一遍，结果记入本片 NOTES.md。

## 合规清单（发布前逐条过）

口播稿、字幕、屏幕大字、标题简介和画面都适用；生成画面同样检查。

1. 股票、理财、投资：尽量连「股票」字样也不提（含「不谈股票」这类否定句）；不出现买卖建议、交易策略、A股、大盘点位，这一类风险最高。
2. 站外引流：不念网址，不说「去搜 xxx」、注册步骤、加群、加微信、私信领取。
3. 规避规则的说法：不用薅羊毛、白嫖、榨干、刷打卡、绕过限制这类词。
4. 广告感：不推荐第三方付费产品，不比价，不提支付渠道。
5. 绝对化用词：不用最、第一、100%、绝对、唯一（屏幕大字同样适用）。例外：「最后」表时间先后且带「之一」，或明确转述他人原话时，口播/字幕可保留；屏幕大字仍不要单独拿「最」当卖点。
6. 描述平台机制：不用「监控」「操控」这类指控性说法，改用「记录」「推荐」这类中性词。
7. 画面：不出现别家 logo 或水印、其他平台 App 界面、盗版或侵权画面、二维码、联系方式、个人信息；生成画面里不能有乱码文字（生成片段本就不含文字，见[生成视频分层合成](assets.md#生成视频分层合成)）。
8. 引导站内内容：只点名平台自己的产品或栏目，不说「去下载」。
9. 用了生成图片或视频时，发布时勾选「内容由 AI 生成」。

验证：发布前把口播稿、字幕全文、全部屏幕大字、标题简介逐条对照清单，抽帧检查画面项，结果写入本片 evidence/review.md。

## 标题和简介

- 标题直接说主题，简单，默认不用问句，不做标题党；作者指定问句标题时以作者为准。
- 简介用一两句说清看完有什么收获，再加三到五个话题标签。
- 标题和简介同样过一遍合规清单。

## 锁定规则

- 口播稿经作者确认后锁定，审片阶段不再改措辞；字幕、屏幕大字只从锁定稿截取。作者事后主动点名要改的除外（不算回头改锁定稿）。
- 分镜交给制作后锁定，规则见[按 TTS 时间戳拆分镜](captions-and-shots.md#按-tts-时间戳拆分镜)。
- 审片的「必须改」只修一轮；建议项写进本片 NOTES.md 的下一条视频待办。
- 封面经用户确认后锁定；后续更换按仓库独立封面规范与用户指定范围执行。
