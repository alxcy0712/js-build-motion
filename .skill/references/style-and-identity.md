# 风格与个人识别

表中列出当前引擎已注册的主题预设。每片的视觉设计与效果组合按共用标准确定；新增内置主题需同步注册、品牌配置和校验。

| theme | 名称 | 关键 token | 适用 |
|---|---|---|---|
| `minimal`（默认） | 极简 | 底 #000、字 #F5F5F7、品牌黄 #FFC712；Inter + Noto Sans CJK SC；竖屏 hero 132；文字弹簧 k100 c25（零过冲）；进场 0.9s、holdMin 1.2s | 机制解释、证据对照、观点表达、品牌片尾 |
| `kinetic` | 动感 | 底 #05060A、品牌黄 #FFC712、默认第二色蓝紫 #5B3DF5；Inter Tight + Noto Sans CJK SC；竖屏 hero 168；文字进场 k380 c28（过冲 ≤4%）；进场 0.45s、holdMin 0.6s | 生动有趣、娱乐化、戏剧化且具有视觉张力的表达 |

| 运行时预设参数 | minimal | kinetic |
|---|---|---|
| 可选推镜 `treatments.drift` | `scaleTo: 1.03, seconds: 5` | `scaleTo: 1.06, seconds: 3` |
| 颗粒 `treatments.grain` | `opacity: 0.03, fps: 24` | `opacity: 0.04, fps: 30` |
| 暗角 `treatments.vignette` | 0.55 | 0.6 |
| 辉光 `treatments.glow` | `blur: 120, opacity: 0.3`，目标 accent / subject | `blur: 60, opacity: 0.6`，目标 accent / text |
| 常规转场 `durations.transition` | 0.7s | 0.4s |
| 甩切 `durations.whip` | 沿用常规转场参数；默认转场列表采用其他类型 | 0.35s；当前管线将 whipPan / glitchCut 的实际时长上限设为 0.3s |
| 节拍 `bpm` | 96 | 128 |

参数权威来源为运行时的 `src/themes/styles/minimal.ts`、`src/themes/styles/kinetic.ts`；转场时长还经过 `src/pipeline/theme-transitions.ts` 计算，微运动轨迹由 `src/themes/liveness.ts` 求值。`scaleTo` 与 `seconds` 定义缓动推进的尺度和时间参数，实际逐帧值按该轨迹计算。表格随代码更新；采用值和当前编码的实际效果分别记录。

本片可用 `style: { "theme": "kinetic", "vignette": 0 }` 关闭暗角，或在 0–1 内调低强度；省略 `vignette` 时使用表中默认值。颗粒继续按主题参数绘制。暗角开启时在最终 RGBA8 合成上加入确定性的 ±1 色阶中性噪声，分散深色渐变的量化色带。

字幕与主题中文统一使用随运行时保存的 Noto Sans CJK SC；Inter、Inter Tight 与 Geist Mono 同样采用内嵌原版文件。恢复来源与摘要见根 README 的字体归因。缺少主题字体时渲染报 `FONT_NOT_FOUND`；`run.json` 的 `facts.fonts` 保存注册文件与完整 SHA-256，`facts.fontUsage` 保存实际文字绘制命中的 Skia 字族。

主题转场列表提供默认推荐。validate 按最终生效主题对推荐外的已登记转场给出 `THEME_TRANSITION_NOT_RECOMMENDED` 警告，并保留显式选择；渲染使用该选择，按语义、连续性与读时验收。未知 ID 及无效输入继续经过 VideoSpec 枚举校验与修复。`riseFade` 前半段淡出旧层、后半段淡入新层，共享切点的无字空档最多一帧；位移保留旧层上移 1.5%、新层从下方 3% 升起。

文字弹簧、字号、进入时长、停留、BPM 和转场列表各自提供局部预设起点；主体、相机、物体互动的幅度、节奏和复杂度由本片创意决定。镜长按实测台词、动作与读时决定，主体和关系承担讲解；各类风格的强度选择和共同验收按[动效语言与制作标准](motion.md)。

所有风格共用必要信息安全区：竖屏 上220 / 下520 / 左72 / 右168；横屏 上72 / 下96 / 左右120。必要标签、来源和屏幕文字按安全区避让，字幕使用自己的版面。场景覆盖完整画幅，主体按镜头焦点与关系选择尺度，关键地标和动作空间保留可见；分层方法见[竖屏构图](layout-and-quality.md#分开三层坐标)。

## 规则的作用范围

个人识别以[个人视频包装规范](style-and-identity.md)为权威，本片沿用固定主题和已确认选择。模型可根据内容独立设计主体、场景、关系、材质、镜头编排和轨迹，并按[本片绘制](drawing.md)选择内置图元、组件副本、自绘或已验证的预渲染路径；各路径共用事实、识别、可读性与连续性验收。

| 类别 | 执行依据 | 验收 |
|---|---|---|
| 内容与正确性要求 | 事实、变量身份、品牌识别、完整读时、字幕可读性与本片已确认选择 | 在当前编码核对对象、因果、最后一项结果与手机阅读；本片固定主题继续按快照执行 |
| 风格默认 | 当前主题色板、字体、文字层级与进退场、字幕版面、包装结构和图形弹簧 | 沿用现有个人风格；minimal 保持精确克制与稳定阅读，kinetic 探索视觉隐喻、角色表演、物体互动与空间接力，并保留观察和反应时间 |
| 可调偏好 | 转场推荐、字号、进入时长、holdMin、BPM、微运动与镜头幅度 | 在个人识别与已确认选择内按内容、实测声音和样片调整；采用值、消费者及可见效果分别记录 |
| 技术硬限制 | 已登记枚举、有效数值范围、字体可用、固定时间与种子、运行时身份和编码条件 | 规格／运行时校验及适用回归；工程检查与视听验收分别保存证据 |

沿用默认时直接执行；内容适配的参数调整在现有 NOTES.md／events.md 记录依据与验证。涉及个人识别体系、固定主题或已确认方案的变更，按用户当次指派与已有授权处理，保留明确要求的选择与审批。方法表、效果清单和示例数值作为可改写的起点，具体实现由模型在本片契约内决定。

`durations.enter` 在通用 theme-stage 的首屏处理处消费；`revealState` 的实际文字轨迹使用 `textReveal`，自绘镜头按自己的调用执行。`holdMin`、主题 `bpm` 与 `maxCharsPerScreen` 提供设计起点；镜长、节拍和字数检查以各自实际消费者及本片读时为准。

文字过冲由 `textReveal` 与 `springs.text` 的校验和钳制管理：minimal 为零过冲，kinetic 上限为 4%。必要文字按最大入场尺度与字形外框预留空间，核对完整动画期间的边界。`layout`、`accent`、容器边缘和相机分别按材质与语义选择参数；数据值、刚性尺寸与品牌路径保持内容约束。持续对象的标签沿用同一状态与锚点，新增文字在取得阅读空间后进入，字幕保持屏幕坐标；同类文字的运动语法在实际交接处统一。

`treatments.motionBlur` 当前由 `whipPan` 消费，在固定旧／新离屏画面上多次采样归一化位移。普通镜内对象、相机和文字使用当前时刻求值。快速动作先按[跨镜连续状态](drawing.md#跨镜连续状态)修正轨迹，再比较原生帧率与局部时间采样；配置值、实际调用和编码效果各自核验。


## 按任务选择表现方式

minimal 以稳定主体、坐标和对照列显现差异；同一条件和单位持续可见，局部更新后留下完整结果。kinetic 建立可辨认对象，用一次主动作证明变化，在关键发现处加强尺度、形状与颜色，随后回到稳定证据段。产品能力、机制流程、数据比较和身份收束各以对应结果验收；短展演按节拍，解释按因果与读时。

## 品牌黄色彩系统

主色 #FFC712 指向当前对象、关键路径和结论，默认第二色 #5B3DF5 区分另一组或过程空间；辅助色按题材选择。深墨 #101116、暖白 #F5F5F7 与灰阶承担阅读和坐标。语义色、实物色保留含义，用标签/形状共同编码。记录“对象/变量 → 职责 → 色值 → 明暗背景文字色”，同一对象跨镜保持身份。

深底用黄聚焦，黄底用深墨正文，蓝紫底用白正文；近似色可选 #FF9F1C/#FFE58A，自然或技术环境可用深青 #146B68。先以同主体同文字比较主辅面积，再在连续换色与 360px 宽编码中复核，灰度辅助检查分类。正文/字幕对比度以 4.5:1 为设计起点，主题默认正文对比继续满足 7:1 校验；半透明、描边、辉光、噪声和实际背景一起取样。快速亮暗变化核对闪烁，优先连续面积迁移和单次揭幕。

## Three.js 与个人风格

三维场景沿用本片 `brand.json` 固定的 minimal／kinetic；渲染入口将同一份主题色板、字体、字级、时长与弹簧参数传给 `createScene`。品牌黄继续指向当前对象与结论，蓝紫区分另一组或过程空间，深色底与清楚的文字层级延续个人识别。三维制作入口见[三维渲染与空间镜头](drawing.md#三维渲染与空间镜头)。

| 维度 | 默认起点 | 验收 |
|---|---|---|
| 形体与材质 | 主体轮廓清楚、尺度统一；图解和卡片采用哑光表面，品牌色用主题 token；产品与角色按原件和定稿材质 | 在全景、特写和手机宽度检查识别特征；实物色、皮肤、衣服和标识保持各自依据 |
| 灯光 | 中性主光加环境补光，接触阴影交代落地与遮挡；默认 `metalness: 0`，roughness 为 minimal 0.9／kinetic 0.7 | 暗部仍能看清脸部和关节，轮廓与背景可分；曝光和环境色调整后复核品牌黄与白字 |
| 图片与文字 | 原件截图保持比例；信息平面使用 sRGB 纹理与 `flatMaterial`，精确色块和标识保留原色；中文沿用 Noto Sans CJK SC | 截图字形、来源与完整结果可读；纹理加载和字体加载完成后出帧；字幕继续在最终画面坐标中合成 |
| 镜头与运动 | minimal 用稳定参照、局部展开和落定；kinetic 用起势、接触、回弹、空间接力与角色表演；透视相机默认 FOV 35°，按内容调整 | 运镜说明关系或变化，主要动作、相机加速与文字阅读错开；落定后保留观察与完整读时 |
| 角色 | 使用已确认的模型比例、服装、表情和材质；全身表演由真实三维关节与适配动作驱动；二维角色平面承担与其素材匹配的动作 | 先确认中性站姿及正／侧／背面，再看连续动作；检查关节弯曲、脚底接触、重心、穿模、背面与表情连贯 |

材质、灯光、FOV 与动作幅度提供可调整的起点，主体设计按内容和样片决定。大转身、行走与跳跃先验证模型的背面、关节和动作片段；单张图片可用于三维舞台中的卡片或立绘，完整角色建模、骨骼绑定和动作制作各自验收。泛光、颗粒和暗角在三维层与最终合成层之间明确一次处理的位置，记录所采用的参数与实际消费者。

## 竖屏 9:16 口播版面默认
适用于 1080×1920 竖屏口播/解说短视频（其他尺寸按高度换算），常量在 `src/themes/shared.ts` 的 `VERTICAL_SHORT_LAYOUT`。
- 字幕中轴线：外框中轴线位于 75%–80% 屏高，默认 77.5%；单行、多行和双语共用该轴，实际字形在框内上下居中。省略 `captions.bottomInset` 使用此默认，显式值用于本片确认的位置覆盖。字幕可低于非字幕安全区的下边界 520，完整字幕框需在当前平台预览中避开底部信息和右侧互动按钮。几何、双语与普通字幕叠加见[字幕外框与底部](captions.md#字幕外框与底部)。
- 屏幕大字基线约 1330；大字下沿与字幕上沿至少相隔 128。用 `bigTextBaselineFor(字幕上沿, 大字下伸, 推镜造成的最大下移)` 按实测字形计算，较近时整体上移，不压缩间距。
- 主视觉中心约 y=1000，主体与大字组成的视觉组围绕它排版；水平仍按画布中心 x=540。
- 验证：每镜头抽一帧，实测外框高、中轴线位置、字形上下留白、大字间距和平台界面避让；固定内容的底部跨时间保持同一颜色，推镜最大倍数帧单独核对。

## 账号默认与每片风格选择
`.skill/brand.json` 保存**账号默认风格**（当前 `minimal`）。每片在初始化前取得主题选择：用户已指定主题或明确委托本片主题选择时，记录并执行；其余情形先询问用户，以 `minimal` 为默认推荐，结合本片任务说明 `kinetic` 备选的效果。默认推荐经用户答复或明确委托后采用。任务表帮助解释两种编排，最终主题按本片选择固定。

主题确定后，显式传入所选值创建项目，再按[沟通原文](workflow.md#沟通原文)补齐问答。`minimal` 与 `kinetic` 二选一替换下面的占位参数：

```bash
node .skill/scripts/video.mjs start <slug> --idea "用户原文" --theme <minimal|kinetic>
```

start 要求显式传入 `--theme`；缺失时报 `THEME_REQUIRED`，在创建项目与备份之前停止。账号推荐值也通过这一参数采用。start 把账号默认与本片选择一起写进该片根目录的 `brand.json` 快照：`theme` 是本片生效风格，`defaultTheme` 是创建时的账号默认，`changes` 末尾记录日期及“显式指定主题”的初始化事实。`workspace.json.brand` 记录同一选择与快照哈希，运行时核对快照未被改动（不一致报 `RUNTIME_BRAND_CHANGED`）。本片 `.engine` 的校验与渲染始终读这份固定快照。

直接调用核心 `validateSpec` 时，显式的 `style.theme` 按规格保留；需要固定手建项目的主题时，传入 `{ brand: loadBrand(本片brand路径) }`。核心账号配置仅参与新片初始化。Linux 手建工作区与命令边界按根 AGENTS.md 的对应流程执行。

主题选择的原文依据保存在 `prompt-history.jsonl`；快照中的自动记录用于标识采用值。`needs-intake` 表示继续处理剩余创作选择，已确认主题继续沿用。当前入口支持在初始化时选择主题；已有影片请求更换主题时，先说明固定快照约束，明确迁移范围、授权与验证方案，实施时保留原版本及其证据。

单片 spec 写了与 `theme` 不同的 `style.theme`：`enforcement: "override"` 时强制改回并给出 `BRAND_THEME_LOCKED` 警告，`"reject"` 时直接失败。更换**账号默认**时才改 `.skill/brand.json` 的 `theme`/`defaultTheme` 并在 `changes` 末尾追加记录（品牌级变更，只影响之后的新片）；已有影片保持各自的固定快照。version 1 的旧配置（`lockedTheme`）继续可读，按生效风格归一化。

## 可选动作编排

初始化选择 `motion-tokens` 时可调用 `enter(theme,'soft'|'snap'|'pop',seconds,role)`、`emphasis(theme,'pulse'|'underline'|'scalePunch',progress,role)`、`exit(theme,seconds)`。返回透明度、位移、缩放或揭示量，由本片显式应用。`stagger(index,'tight'|'normal'|'loose')` 分别使用 0.04／0.08／0.14s；`beats(start,reveal,emphasis,settle)` 返回三段绝对时间。沿用主题 bezier 与 spring 参数，新增 accent 弹簧限制过冲 ≤3%，minimal 阅读 token 保持零过冲；`validateMotionToken` 核对显式参数。既有默认 token、字体、主题和 IP 保持原值。

连续目标使用 `springTrack`，相机轨迹使用可选 `camera-path`，编排与落定按[电影化运镜](direction.md)和[布局 QA](layout-and-quality.md#渲染期布局-qa)复核。暗角与 ±1 噪声保持像素语义；不透明主管线使用每渲染器有界遮罩缓存，并在独立帧边界清除 Skia 绘制记录。透明中间面的公开 helper 保留原有 alpha 行为。

## 防死帧
稳定阅读、主体信息变化与氛围运动分别检查。静止指标定位候选区间，阅读与情绪停留按用途验收；微运动的参数检查覆盖所选轨迹，信息推进按对象和关系的实际变化验证。

- **本地实拍剪辑**：本地剪辑软件按素材动作、镜头节奏与剪辑习惯处理停留，`microMotionAt` 属于代码镜头的可选实现工具。该函数在本地实拍剪辑流程中免于强制调用；有意静止的用途与实际观测范围写入审片记录。
- `liveness` 提供可选氛围运动的预设轨迹，校验器验证其参数与窗口位移。`theme_stage` 在显式动态 cameraMove 且省略 cameraPath 时采用主题微运动；静镜保持固定相机与背景坐标，显式 cameraPath 独立控制相机。颗粒作用于完整场景；minimal 与 kinetic 默认不使用扫光（用户认为扫光碍眼）。字幕按[普通叠加层](captions.md#字幕外框与底部)绘制。实际信息推进依据对象、关系和结果的变化验证。
- **信息/代码镜头**：按口播关键词分拍显现、点亮、拆解或对照，推进强度服从内容；阅读、观察或情绪停留登记明确用途。空档先检查叙事和读时，主体动作承担需要发生的信息变化。细则见[信息卡与清单分拍](drawing.md#信息卡与清单分拍)。
- **稳定阅读**：`motion_stage` 与 `theme_stage` 均可采用 `cameraMove: "static"` 并省略 `cameraPath`；存在 `cameraPath` 时管线优先采用该路径。本片绘制保持页面、证据和标注的共同坐标，按语义安排进场、划线和重点切换。阅读停留、结果展示、反应和片尾身份可保持静止，记录起止时间与用途。静止候选通过读时与信息用途验收，循环漂移按明确的内容需要采用。
- 生成片段按内容选择变速和镜长，见[生成视频分层合成](workflow.md#素材选择与生成视频)。正反往复仅用于已验证可逆的循环动作；受力过程、口型和操作演示保持事件方向。代码管线里实拍慢放建议不低于约 0.6×；时长不足时优先换未用区间、补充素材或调整镜长。
- 审片：`node .skill/scripts/video.mjs <slug> exec node .engine/scripts/dead-frame-qa.ts out/final.mp4 [--json]`，比较相隔 0.5s 的帧（灰度、块平均、扣除颗粒噪声底），报告无可见变化的候选区间；候选诊断退出码 0，工具运行失败使用非零码；`--holds evidence/holds.json` 接收带用途与理由的时间区间数组。连续静止 >1s 的区间写入本片 NOTES，标明阅读、结果、观察或情绪用途；其余停滞按事件设计修正。

## 个人 IP 使用规则
- IP 是小幅美术，**不当主视觉放大**。生成视频里的角色同样不放大超过源像素，见[生成视频分层合成](workflow.md#素材选择与生成视频)。显示边长 ≤ 源尺寸 512px（rig 头/身部件），推荐 256–384；超过即 `IP_UPSCALE` 校验失败（按实际输出像素换算，4K 输出同样受限）。
- `scenes[].ip` 默认不出现。只在两种情况使用：
  - `role: "identity"`：身份声明或需要时，例如片尾小签名（默认 288px，底部居中）。
  - `role: "actor"`：讲解动画中的演员，例如骑车、操作电脑（默认 384px）。
- 写法：`"ip": { "role": "identity", "size": 288, "position": "bottom-center", "expression": "happy" }`；`position` 可选 `bottom-center | bottom-left | bottom-right | center | custom`（custom 需 `x`、`y`，0–1，y 为角色底边）。旧写法 `ip: true` 自动降级为 288px 身份署名并告警。
- 纯文字镜头不放 IP，标题居中；身份署名在底部时标题略上移。
- 片尾头像与个人 IP 落款是经用户确认后采用的专用身份版式，与收尾口播「我是澄记，用计算机思维想现实。」同时采用或同时省略：头像居中、显示边长约 400px（仍不超过 512），规格见[片尾头像与个人 IP 落款](style-and-identity.md#片尾头像与个人-ip-落款)。

## 渲染前自检
出片前逐项过一遍，并在抽帧（每镜头一张 + 片尾）上实测：
- **主体居中**：采用居中构图时，按画布中心（竖屏 x=540、横屏 x=960）排版；偏置构图在镜头计划中注明焦点与用途。推/拉镜围绕已选焦点，安全区用于内容边界检查。居中构图实测：`node .skill/scripts/video.mjs <slug> exec node .engine/scripts/centering-qa.ts <still.png>... [--exclude x,y,w,h]`，内容包围盒中心水平偏移 ≤ 2%（角落署名用 `--exclude` 排除）；代码里用 `measureContentCenter` / `isCentered` / `withinSafeArea`（`src/qa/centering.ts`）。
- **安全区与画幅**：推镜到最大倍数时，必要文字与标签保持平台避让，关键地标和关系仍可见；主体尺度与环境覆盖按[三层坐标](layout-and-quality.md#分开三层坐标)检查。字幕单独核对外框、读时与界面避让。
- **防死帧**：`dead-frame-qa.ts` 的候选区间逐段核对；有意阅读与情绪停留记录时间和用途，其余停滞按事件设计修正。
- **文字**：字形正确，各项文字按对应语义时点进入，完整结果保留读时；新旧文字交接清楚。

|---|---|---|
| 品牌色 | 主色 #FFC712 指向当前焦点、关键路径或结论；默认第二色 #5B3DF5，其他辅助色按内容选用；主体实物色与数据语义色保持各自含义 | 读取固定主题的 `palette`，颜色职责、配色范本和对比检查按[品牌黄色彩系统](style-and-identity.md#品牌黄色彩系统)执行 |

| 文字层级 | 标题／关键数字、解释正文、来源／辅助标签各有稳定层级；同主题跨片沿用字体、字重和层级职责 | 字体与字号从本片主题 token 起步，字幕按[短字幕规范](captions.md)独立排程；实际字体、手机读时与长文本换行逐项检查 |
| 信息容器 | 人物条和资料卡采用整齐矩形、清楚边界与单侧黄色标记；主体信息优先，来源在独立辅助区 | 同一组件的边线、留白、对齐和文字层级共用一组样式；原始截图与品牌标识保留真实外观，明暗变体只调整承载层 |
| 动作语法 | 当前对象出现 → 重点被标记 → 结果落定 → 完整阅读 → 收束或交给下一镜 | 用本片主题的进入、退出与缓动参数；同类组件共用进入方向和退场逻辑，语义时点和完整读时按[共用动效标准](motion.md)验证 |
| 个人形象 | 需要创作者身份或本人参与讲解时，沿用已指定 IP 的身份特征与现有授权素材 | 素材复制到本片并登记来源；尺寸、位置和身份／演员角色按[个人 IP 使用规则](style-and-identity.md#个人-ip-使用规则)核对 |
| 声音 | 人声承担内容，环境声建立空间，短提示音对应进入、强调或完成事件；同类事件沿用选定的声音与强弱关系 | 沿用执行角色的配音授权；已确认声音标识按版本复用，其余音效按本片内容选择，实测与试听见[音视频流程](workflow.md) |

`minimal` 与 `kinetic` 共用上述识别层，分别采用稳定参照和较强状态变化。每片主题继续按[账号默认与每片风格选择](style-and-identity.md#账号默认与每片风格选择)取得选择并固定；识别规则随主题调整动作强度，字段顺序和品牌色职责保持一致。

正片的容器和收尾从本片内容设计；`assets/douyin-cover/` 中的模板与版式保持独立封面用途。镜头间通过主体动作、景别、空间和证据组织变化，同类包装在需要时出现。每片特色以实际表达和记忆点检验，元素数量按信息需要确定。

## 片尾头像与个人 IP 落款

片尾卡由个人 IP 头像与「澄记 / 用计算机思维想现实」落款组成，与片尾口播「我是澄记，用计算机思维想现实。」配套出现，两者同时采用或同时省略。规格取自已发布团队影片的共同做法，以实际编码画面为准；主账号与 5W1H 账号共用同一规格。是否采用由用户逐片决定，问答与记录见[创作问答](workflow.md#创作问答)。

### 采用与口播

- 每条新片按创作问答询问用户是否需要片尾卡；用户回答后记录在本片，后续制作与改片沿用该答案，不再重复询问。用户未回答前片尾保持待定，不默认加入或省略。
- 用户确认采用时，片尾口播使用「我是澄记，用计算机思维想现实。」，前一句从本片内容自然承接，写法见[口播稿写法](workflow.md#口播发布与锁定)。片尾卡、口播和对应字幕作为一组制作与验收。
- 用户不采用时，本片既不放片尾卡，也不念「我是澄记，用计算机思维想现实。」；成片在正片内容的结论处结束，最后一句落在本片内容上。

### 时序与动作

| 项目 | 规格 |
|---|---|
| 位置与时长 | 全片最后一镜，在前一句与片尾口播之间的停顿中切入，比口播首字早约 0.4–0.6s；总时长按“提前量 + 实测口播时长 + 完整停留时长 + 可选淡出时长”计算。已有样例的 3.9–4.0s 仅作参考，本片按实际音频确定镜长与片末 |
| 进入 | 由上一镜硬切或约 0.4s 的上移交叉淡化进入。头像从开场起可见，或在约 0.6s 内缓出淡入并上浮约 30px；名称与标语在约 0.4–0.6s 内缓出淡入，带约 18–24px 上浮，minimal 可加由约 10px 到 0 的去模糊 |
| 与口播对齐 | 名称最迟在读到「澄记」时完整可读，标语最迟在读到「用计算机」时出现；两行也可在口播开始前一起出现。使用可动 IP 时，口型按片尾口播的音量包络驱动，口播结束后闭口 |
| 稳定停留 | 进场完成后固定镜头、头像、名称和标语坐标；身份阅读段保持稳定，眨眼和按真实口播驱动的口型可保留。需要角色表演时按本片内容单独设计动作 |
| 收尾 | 口播结束后整组完整停留约 1.5s，再结束于最后一帧；选择淡出时，在完整停留之后另加约 0.6s 将全画面淡至黑色并同步淡出剩余声音，该段计入总时长。本片选定方式并记录 |

例如提前量 0.5s、实测口播 3.0s、完整停留 1.5s，片尾总长为 5.0s；选择再淡出 0.6s 时，总长为 5.6s。先取得配音及词级时间，再确定片尾起止与全片时长，完整保留口播和落款读时。

### 实现与记录

确认采用后优先调用 `drawing/scenes/end-card.ts` 的 `drawEndCard`（可复制 `end-card` 组件）。传入本片头像绘制回调、固定主题、整段字幕最小外框上沿、实测词表与已选名称行写法；`spokenWordStart` 支持跨词项锚定。helper 反推名称／标语进入时点，按真实字形安排间距，停留期间保持位置固定，并登记审片追踪。头像、颜色、字体与固定口播沿用上述规格。已有确认版式可继续使用，配合 `withLayout` 分别登记 avatar/name/slogan 的 `endCard` 元数据：wordStart、holdStart、holdEnd 使用全片秒数；名称在词起点达到完整可读透明度，标语至少达到 80%。实际最迟可见帧取 ceil(wordStart × fps)。

自绘文字弹入调用 `motion/text.ts` 的 `textPop` 或 `drawTextEntrance(kind: 'pop')`，参数来自主题 `textReveal.positionSpring`，minimal 零过冲、kinetic ≤4%；逐行揭示调用 `lineReveal` 或 `drawTextEntrance(kind: 'line')`，默认 easeOutCubic、每行 0.4 秒、错开 0.16 秒，可按内容覆盖时长与错开。`drawTextEntrance` 保留回调的字体／颜色，并自动登记实际进入区间。已有自绘曲线用 `withLayout` 的 `textMotion` 登记起止与缓动，再由逐帧实测验收。通用道具缓动及现有主题参数保持各自用途。

采用记录写入 `evidence/events.md` 的“个人包装选用”表，注明名称行写法、是否显示账号署名、收尾方式和口播实测时间；`brief.acceptance` 写入片尾卡与口播同步的验收目标。

## 每片选用与版本记录

1. **开工**：读取本片固定主题与用户选择，在 `NOTES.md` 写明本片沿用的识别规则、需要的组件组、与默认规则的差异及依据。已有视觉选择持续复用，剩余重要选择按[创作问答](workflow.md)处理。
2. **分镜**：在 `evidence/events.md` 的“个人包装选用”表填写实际采用项：目录编号／组件组、表达任务、镜头、样式与变体、实现入口、验证状态。全部镜头继续按内容编排，组件状态与语义事件对齐。
3. **实现**：先核对本片已有组件与契约；可用画法沿用本片副本，新增画法写入本片 `src/`。同一组件的文字、素材与时长作为内容输入，字体、色彩、间距、边界与进退场从同一份样式读取。实现状态使用“待实现／已实现／样片通过／当前编码通过”，分别附源码或实际证据。
4. **验证**：为本片实际采用的画幅、明暗背景和内容长短选择代表性样例，包含最拥挤的一镜；在正常速度与 360px 宽下核对主体、字幕、人物条、来源和 IP 的关系。进入、停留和退出都保留连续观察证据。
5. **复用**：已确认方案记录其版本、样式参数、素材来源、适用条件和样片；跨片采用先核对共享层是否已有对应规范或组件。需要沉淀的通用实现通过核心维护（由宿主按仓库核心维护规范执行）独立保存至权威位置，新片从核心初始化所需副本。核心与模板保持独立于 `projects/`。

旧片按自己的 `guide/`、固定运行时和已确认选择执行；新规则用于新片，已有影片的升级依用户指定范围实施。主题、源素材与成片证据分别保留版本身份。

## 审片验收

在 `brief.acceptance` 中加入本片可观察的包装要求，在 `evidence/review.md` 记录实际结果；采用 Production 的结构化审片时，将相应证据归入现有 captions、sync、quality 和 rights 检查。

| 检查 | 通过条件 |
|---|---|
| 身份与一致性 | 所有已采用组件的黄色职责、字体层级、笔画、容器和同类进退场一致；本片差异有选择依据，个人 IP 符合既有身份 |
| 内容与密度 | 每个元素有对应台词或画面任务；当前重点清楚，人物条、字幕、来源与主内容互相避让，段落构图随内容变化 |
| 语义与阅读 | 实测触发、强调和落定吻合讲解；短字幕、引文、单位与必要来源在目标画幅可读，最终结果有完整读时 |
| 证据与边界 | 原件、来源、画面性质和采用权利准确；封面素材用途独立；收尾、配音及身份使用符合执行角色约定；未采用片尾卡的成片不含收尾口播 |
| 片尾卡 | 仅在本片记录了用户确认时出现；头像素材、排版、主题颜色、字体层级与动作符合[片尾规格](#片尾头像与个人-ip-落款)；名称与标语按片尾口播实测时间出现，口播后完整停留，字幕与安全区不冲突 |
| 实现与观察 | 选用表可定位实际源码和当前编码，最拥挤镜头与代表性变体有检查记录；待实现或待观察项如实保留状态 |

规范接入与工程检查验证继承和执行路径；具体外观、声音和成片统一程度以已采用组件的样片及当前编码观察为依据。用户明确要求的视觉验收按已有约定执行。
