# 视频剪辑元素目录

本目录整理 17 类、154 项素材与组件，以及 23 组处理方式，供策划时按表达任务检索与扩展。元素采用和固定外观按[个人视频包装规范](visual-identity.md)执行；实际可调用能力通过本片 capabilities、组件目录与源码核实。编号用于策划和审片记录，所需画法按本片实现状态登记。

元素、内容、样式和动作分别记录。例如资料截图作为内容，引用卡提供容器，品牌色与文字层级规定样式，滑入与停留规定时序。专项模板可由通用元素组合；同一组件的画幅、明暗、长短和动静版本归入其变体。各片选用以内容需要、素材依据、权利和实际工具为准。

## 处理方式

转场、动画、合成与声音处理分别服务于内容组织、注意力交接和可读性；按[共用动效标准](motion-language.md)选择并验证。画面中的按钮、二维码与推荐位属于视觉内容，实际点击或跳转能力由发布平台提供。发布用途与账号规则按[发布规范](douyin-publishing.md)核对，元素入目录表示可检索的类别。

### 剪辑连接与转场

| 编号 | 处理方式 | 作用 |
|---|---|---|
| P01 | 硬切／跳切 | 直接连接镜头，或压缩时间、形成节奏 |
| P02 | 淡入淡出／黑场白场／叠化 | 通过亮度、纯色画面或前后重叠完成过渡 |
| P03 | 擦除／推拉／滑动／缩放／旋转转场 | 通过画面移动或区域替换衔接镜头 |
| P04 | 遮挡／遮罩／形状转场 | 利用人物、物件或图形遮住画面的时机切换 |
| P05 | 光效／故障／变形转场 | 通过光、干扰、形态变化完成过渡 |
| P06 | 匹配剪辑／动作衔接 | 利用形状、构图、视线、动作关系连接镜头 |
| P07 | 交叉／平行剪辑与蒙太奇组合 | 组织多个镜头的时空关系、意义与节奏 |
| P08 | J-cut／L-cut／声音桥接 | 让声音与画面的切换时刻错开 |
| P09 | 回放／重复／节拍剪辑 | 通过再次呈现、重复、节拍对应控制信息和节奏 |
