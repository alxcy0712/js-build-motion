# 短字幕与语义分镜

旁白段落承载连续表达，字幕条目承载一次阅读，镜头承载一个可见事件。用同一脚本与实测配音时间连接这三层：标点提供字幕断点，信息变化决定镜头与动作的推进。

## 字幕拆分

先按逗号、句号、问号、感叹号、分号与冒号拆成小句，句读边界保持独立。显示文字去掉句读、引号和括号等标点，枚举中的顿号可以保留。人物与模型名称、数字与单位、比较关系和因果限定保持可读的组合。中文讲解通常从每条约 10–20 字、每次一至两行试排，结合字号、画幅、手机显示与语速调整。

引擎的 buildCaptionTrack 先按标点和可用宽度拆分单语字幕，再统一生成 cue.text 与词级高亮的显示文本。同一小句内的宽度拆分可合并短词或前移完整词组边界；逗号等句读两侧各自成条，读时不足 0.8 秒进入 QA 复核。小数、千位数、版本号、技术标识、英文词和 URL 内承载语义的符号保留，如 1.4、1,000.50、v2.1、Example-R2；这些符号与数值、技术词共同验收。超长完整词组进入排版复核。

字幕起止取该小句自身在词级时间戳里的首字开始与末字结束，再加阅读余量并核对句间停顿。交付前逐字核对：每个有声字的中点都落在某条字幕的显示区间内；较短条目保持句读边界，复核实际语速、停顿与阅读余量。缺少词级时间、供应方单词跨过多个小句或词表与脚本匹配失败时，估算时间只用于排版预览，实际同步保持待复核。画面字幕、SRT、VTT 与高亮共用同一 cue 文本与词时间，源朗读稿另行完整保存。双语输入先准备逐条语义对应的小句，逐条核对主字幕、译文和声音；引擎保留已提供的双语对应关系，长段译文先人工拆成对应短句再进入正式同步验收。本仓库引擎 `buildCaptionTrack` 已按词级边界计时；单片自写字幕轨复用同一规则并做上述逐字核对。

## 字幕外框与底部

保留字幕外框、圆角与底色。字幕外框中轴线安排在画面高度的 75%–80%，即距底部 1/4–1/5；默认取 77.5%，1080×1920 时为 y=1488。单行、多行与双语共用这条中轴线，框高变化向上下展开。h 取包含全部行、双语间距和上下内边距的外框总高，默认框顶为 0.775H − h/2；显式 captions.bottomInset 用于本片已确认的位置覆盖。

该比例是默认制作位置。发布前用当前平台的界面预览核对完整字幕框与字形，给底部账号名、标题简介、音乐等信息及右侧互动按钮留出空间。文案行数、附加组件、设备画幅或最长双语条目造成重叠时，按本片实际预览上移或收窄，记录覆盖值与检查范围。

文字以实际字体的 actualBoundingBoxAscent / actualBoundingBoxDescent 计算整个字形块的上下边界，在框内上下居中，行间保持统一基线间距。用含中文、Latin 上下伸字形的单行、两行和双语实测上下留白，并从编码帧复核。主体与大字继续遵守非字幕安全区，与字幕外框保持约定间距。

字幕作为普通叠加层绘制在完整场景上，底板沿用所选字幕样式的外框范围，底部其余区域保留场景画面。颗粒等氛围处理按场景画幅绘制，字幕在其后叠加；两套主题默认不使用扫光（用户认为扫光碍眼）。按单行、多行、字幕空档和转场取样，验证框外场景完整、字形居中、外框中轴线与字幕可读性；实拍镜头按本片构图与字幕承载层单独验收。

字幕改片复用原音轨和词级时间，保留原时长与配音语速；实测、封装和身份核对按[音视频流程](workflow.md)。字幕换行、每条时长和实际字号在当前编码中核对。

## 分镜与画面推进

从台词中找出问题、动作、比较、结果、转折与情绪落点，写成语义节拍。每个节拍明确观众此时应理解什么，以及对应的起始状态、可见变化和落定结果；长段落据此安排子镜或同镜内的阶段动作。字幕切换可以继续同一动作，也可以交接焦点；镜头切换配合信息与情绪的变化。

语义节拍写入[分镜主表](direction.md#从内容到连续状态)的表达、visualIntent 与声画锚点列。人物故事可用视线、动作和环境接力，产品展示可用细节、操作与结果接力。完整旁白可跨视觉切点连续播放；同镜内动作由本片代码按镜内时间求值。Production 变更通过 apply → compile 传播，普通 Director 项目通过 direct compile 更新。

## 中文语义事件排程

直接复用 out/audio/ 或 out/audio-preflight/ 的 narration-timing.json 与原词表；词时间为相对影片开头的实测秒数。先核对 specHash 和中文字词对应，再把指定词的 start/end 写入实际时间线，主表引用必要锚点。中文词组可能横跨多个词项，采用首项 start 与末项 end；目标词位于一个更长词项内部时，整项时间只提供范围，峰值通过实际试听定位并登记偏移。缺失或失配的词时间沿用现有估算预览与 pending 流程。

每个语义事件登记三个可复核时点：

| 时点 | 排程与求帧 |
|---|---|
| 首次显现 firstVisible | 先写“可见”的条件，如主词达到正常字号与可读透明度；在语义词开始前完成必要准备。要求时刻之后首次发生时，取 ceil(t × fps)；记录实际帧及偏移 |
| 强调峰值 emphasisPeak | 取指定词的实测重音；原词 start 可作为初始锚点。用 round(t × fps) 对齐最近帧，误差上限半帧；放大、位移或颜色达到峰值后回到可读状态 |
| 动作完成 actionComplete | 数值落定、连线抵达或最后一项呈现完成；用 ceil(t × fps) 对齐，固定时间求值在该帧及随后帧保持最终状态 |

准备、主动作与落定各自写明时长；若动作必须在关键词处完成，从 actionComplete 反推开始时间。首次显现与强调峰值可以在同帧，也可以先显现再强调，关系依据本句含义。字幕的逐词高亮继续使用 buildCaptionTrack/activeWordIndexAt 的原词时间。

完整读时从最终内容完成开始计算。清单用 max(所有项 actionComplete)，数据比较用最终精确值与必要单位、条件全部落定的时刻；readingEnd = complete + 本片选定读时。以实际帧差计算读时，例如最后一项第 72 帧完成、第 108 帧结束阅读，在 24fps 下完整读时为 1.5 秒。下一动作或切点落在 readingEnd 之后；早于完成的逐项读时仍可帮助理解，各自记录。

用固定帧核对首次显现前一帧、显现帧、峰值两侧、完成帧与阅读结束前一帧，再正常速度播放原配音。时间线保存语义词或词项范围、实测锚点、偏移、三个实际帧和 readingEnd，主表说明其用途；完整清单和数字最终状态分别核对。音效接触、音乐重音及编码身份按[音视频流程](workflow.md)复核。

## 艺术感与长镜头复核

选定服务主题的构图、材质、光线与运动母题，并在关键段落落实。概览建立空间或关系，细节展示变化，结果镜头保留阅读与情绪停留。前景、中景、背景各有运动或光影作用，主体动作与相机路径围绕同一焦点排时序；运镜按[电影化运镜](direction.md)验证。标题、说明和来源占据必要的阅读位置，视觉权重集中于当前事件。

逐段检查开头、四分点、中点与结尾：记录新信息出现、焦点交接、主体变化和静止停留的用途。前几秒揭示结束后，后半段应继续完成讲解、动作、尺度发现或有理由的阅读停留。相邻镜头比较主体、关系、景别与留白；把原有的列表改为按讲解顺序发生的过程，把技术结论落实为选择、流动、压缩、比较或验证的可见结果。

总帧数按实际成片的时长和 fps 核对，同时报告秒数、帧率和分辨率。艺术感与信息推进依据当前编码的连续观察评价；帧数用于描述成片规格。

## 验证

代表性短样片覆盖一组短字幕切换、一段长旁白的内部推进、重点机制动作和相邻切点。用原配音正常速度播放，核对字幕闪现、提前或滞后、主体遮挡、局部裁切、转场重影和结论停留。结构 QA 报告字幕条数、最长文本、最短停留和估算条目；真实字体测量与编码画面确认每次行数、字号及安全区。

在 evidence/review.md 保存当前视频身份、字幕与节拍时间码、观察范围、问题和复核结果。字幕、声音与动态审片分别标注实际状态；具体规则和镜头修正通过样片后再进入主片。

## 按 TTS 时间戳拆分镜

适用条件：口播稿已锁定（见[锁定规则](workflow.md#口播发布与锁定)），配音已产出逐字或逐词时间戳（豆包另有句级 sentences，见[音视频流程](workflow.md)）。时间戳出来之后再拆分镜。

- **句间切点**：上一句末字结束与下一句首字开始之间空隙的中点（`gapMidpointCuts`，`src/motion/shot-timing.ts`）。
- **句内切点**：下一短语首字开始前约 0.05 秒，不早于上一短语末字结束（`phraseCut`）。
- **卡点**：强调词的大字、动作、音效对齐该词首字时间；精确到帧的排程按上文[中文语义事件排程](#中文语义事件排程)。与音乐拍点的吸附见 `snapCutsToBeats`，只做小幅微调。
- **字幕**：按实测口播同步并留阅读余量；短于 0.8 秒的条目按上文[字幕拆分](#字幕拆分)进入复核。
- **节奏起点**：竖屏解说每镜 2.5–5 秒、大字强调镜 2–3 秒可用于试排，最终镜长按实测台词、动作和完整读时确定。转场按[每镜意义](motion.md#创作主线)选择，静镜或数字化运镜路径按[电影化运镜](direction.md)执行。

采用共用[五列分镜主表](direction.md#从内容到连续状态)，锁定稿按 lineId 引用，字幕与素材出入点从实际时间线读取。复杂镜头补必要景别、运镜、IP动作及生成/代码分层；屏幕大字优先保留锁定稿中的完整语义，改写沿本片授权。精确参数由时间线和实现代码保存。

版面：竖屏口播沿用[版面默认](style-and-identity.md#竖屏-916-口播版面默认)与[字幕几何](#字幕外框与底部)，保留字幕中轴线、大字间距和视觉中心；主体与场景按[三层坐标](layout-and-quality.md#分开三层坐标)组织，平台遮挡按实际预览适配。章节导航条（如有）放在顶部安全区内。画面合规见[合规清单](workflow.md#口播发布与锁定)。

锁定：分镜交给制作后锁定，审片阶段只改时间戳和叠字，不回改分镜；增删镜头或改变生成/代码分层时才重拆，并在 NOTES.md 记录原因。

验证：用原配音正常速度播放切点附近各 1 秒，核对切点落在句间空隙、字幕无闪现、强调词与大字/动作同帧；分镜表口播列与锁定稿逐字一致；用词级时间戳跑一遍「有声字是否都落在字幕显示区间」检查，结果写入本片 evidence/review.md。

### 补录口播后的分镜回填
只改少数句子、其余句子不重录时：新时间戳出来后，从第一句改动的镜头起整段重算切点与镜长，改动之前的镜不动；屏幕大字、信息卡上的单位与数字与新口播一致（中国常见单位写法见[抖音发布](workflow.md#口播发布与锁定)）。分镜表附一张「素材使用对照」：每个 B-roll 文件列出使用镜号与源出入点，优先采用新区间；再次使用按[引用与复用](workflow.md#素材选择与生成视频)登记新增分析或必要持续用途。

## 剪点建议

`qa --cuts evidence/cuts.json` 读取人工复核的词级样本区间与输出时间映射。证据包含 fps、sampleRate、mapping（verified／unknown）、cuts（id、frame、previousStartFrame、nextEndFrame）、words（text、startSample、endSample、status、source）。所有 sample 坐标使用当前输出音轨；已有源词表可用 `qa/cuts.ts` 的 `mapCutWords` 按选段起点、输出起点、源／输出采样率转换；跨越选段边界的词保留 clippedStart／clippedEnd，边界上的残词继续检查。

可靠 observed 词区间及 verified 映射确认切点落在词内时返回 error；估算、未知映射及缺少试听依据的空档标 pending。候选列出原／建议帧与样本、变化量、附近词和停顿、前后片段长度及声音同步影响。检查保持文件与剪辑原样，`applied=false`。用户确认具体候选后修改项目，重验词、声音尾部、镜长、字幕和操作锚点；估算词表按待复核证据使用。
