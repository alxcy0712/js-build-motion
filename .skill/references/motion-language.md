# 动效语言与制作标准

适用于各类视觉风格中的动作、形变、运镜、转场与阅读节奏。目标是让观众认清对象、追踪变化、理解结果，并在关键发现处获得惊喜。视觉强度服从内容任务；实际采用的风格沿用本片约定。

本文件规定跨风格的表达原则、设计流程与共用验收；[风格选择](styles.md)规定各风格的色彩、字体和动作强度；[动效设计](motion-design.md)提供形变、轨迹与具体效果的实现方法。新增风格与效果沿用本文件的语义、连续性、可读性和现实约束，再补充其适用条件与专项检查。

风格规定整片的视觉与运动特征，效果是镜头中采用的具体手法，同一效果可用于多种风格。内置主题 ID 与效果接口以当前运行时契约为准；新增设计先在本片验证，需要成为内置能力时再按[核心维护](maintenance.md)扩展契约。

## 创作主线

每次创作、恢复会话和扩展风格时，以以下原则核对方案；用户当次要求与已确认选择决定本片范围。

- **按目的选择判断标准**：明确本片希望观众理解、感受或采取的行动，以及当前段落的首要目标和取舍。解释、产品证明与情绪叙事各按[设计判断](design-learning.md#先约定要发生的体验)评价。
- **先看懂，再形成记忆点**：让观众认清对象、追踪变化、理解结果。每镜回答下文的三个问题；主体、关系与证据承载讲解，文字承担必要的问题、标签与结论。
- **表现力来自内容**：形变、转场、运镜和颜色变化对应当前主题、台词或情绪；关键发现与普通段落形成强弱层次，结果保留完整读时。风格差异统一见[任务与编排](styles.md#按任务选择表现方式)。
- **形成自己的视觉体系**：围绕品牌黄 #FFC712 分配颜色职责，保持变量身份与实物特征。从参考提炼机制，再独立设计本片的对象、母题、构图和声音。
- **保持跨片识别**：按[个人视频包装规范](visual-identity.md)沿用字幕、人物条、资料卡、标注和收尾的共同结构；元素按表达任务出现，主体与镜头按本片内容发展。
- **以事实与成片验证**：写实层遵循现实约束，示意层说明简化；外部资料按[素材规则](assets.md#外部资料的引用与复用)核验来源与用途，复用对应新增分析或必要持续用途。工程检查、动态观看和试听分别记录证据。

新增参考、效果与风格先说明服务的内容、适用条件和验证方式，再进入本片试排。完整粗剪与当前编码按下文闭环复核；具体时长、效果清单和历史样本按本片条件选用。

## 逐步拆解参考

先核对参考身份、版本、时长和观看范围；同一作品的成片与界面录屏关联为一组。全片联系表定位段落，关键转场按源帧率取连续帧，正常速度声画观看检验节奏。参考只有静帧时，记录构图与状态；运动曲线、声音同步和制作技术保留待验证。

提示词记录作者要求，视频取样记录实际实现，源码与实验提供技术证据。分别标注原始提示词、站方改写和自己的推断；同一项要求在成片中是否实现，按对应时间码核对。点赞量和提示词长度仅作为样本背景，质量判断落在对象、证据、连续性与可读性上。

提取时先填写“可见机制 → 适用任务 → 本片改写 → 验证方式”。参考中的固定时长、BPM、画幅、循环、效果清单和逐拍动作按各自用途保留为候选；本片时序由实际内容与声音确定。循环用于明确需要首尾衔接的片段，普通结尾保留完整结果与身份读时。各风格的选用与编排见[按任务选择表现方式](styles.md#按任务选择表现方式)。

在本片 NOTES.md 或 evidence/ 中填写以下观察，再用自己的内容重新设计。通用方法的公开来源与归因集中在根 README.md；本片采用的具体来源、许可、素材和时间码保存在本片。

| 拆解层 | 需要记录的细节 | 转成自己的设计 |
|---|---|---|
| 目的 | 本段在全片中的作用、台词或屏幕主张、观众得到的信息 | 用一句话写本片这一段的结果 |
| 状态 | 起点、触发、推进、峰值、落定、阅读结束的帧号 | 先画前后两帧，明确新增关系或结果 |
| 形状 | 主体、轮廓、孔洞、遮罩边缘、语义地标与拓扑变化 | 从讲解对象选择母题，指定各部分的对应关系 |
| 运动 | 位置与尺度轨迹、启动差、加减速、接触、过冲、停止 | 分开安排主体、相机、次层；曲线按受力或表达任务选择 |
| 转场 | 旧镜最后焦点、接力对象、遮挡时刻、新镜第一焦点 | 说明保留什么，以及这次接力表达什么 |
| 色彩与文字 | 各色职责和面积、明暗关系、背景切换、文字层级与读时 | 固定品牌与变量身份，给关键内容留稳定阅读窗口 |
| 声音 | 实际听到的触发、重音、落定声和安静区间 | 按本片实测配音重排，记录实际试听范围 |

提炼机制后，从本片主题独立设计对象、配色、构图、镜头次序与声音。用自己的分镜与参考并排检查识别特征；整体表达过度依赖原作时，回到内容重新选择母题。实现细节见[形状接力](motion-design.md#形状接力)。

## 每镜先回答三个问题

1. **视频的主题是什么？** 写清当前镜头推进的核心问题或主张。
2. **这句台词／这个镜头有什么意义？** 指定要看清的对象、关系、证据或情绪变化。
3. **哪种动作与运镜能展示它？** 给出静镜、主体动作或相机动作的选择理由，写出观众将看到的新信息。

据此按镜头需要安排「起始状态 → 触发 → 主动作 → 次级响应 → 落定 → 阅读／观察 → 下一镜接力」。各阶段可合并；静镜填写观察或情绪停留，次级响应按实际动作填写。同一时刻设置一个主要注意目标；文字进入、主体峰值和相机加速按注意力交接错开。先用几何粗剪走完整时间轴，再验证复杂形变；两级预演见[导演计划](direction.md)。

主题与镜头意义决定转场含义。旁白主导段用实测词句定位语义时点，音乐主导段按画面事件与实测拍点排程，无声段按动作、观察和阅读安排时序。为关键转场填写一句「通过……，观众看见……」。复杂转场在粗剪中与普通切镜比较理解与情绪效果：效果相近时选普通切镜；强化效果明确时保留复杂动作。

| 镜头意义 | 可选动作／接力 | 必须保留的证据 |
|---|---|---|
| 揭示内部机制 | 推入孔洞、局部窗口、遮挡揭幕 | 入口与内部位置可追踪，落定后看清结构 |
| 多项输入形成结果 | 多边形汇聚、节点连接、部件组装 | 输入身份、处理顺序与输出对应 |
| 拆解／分类 | 轮廓分块、分层展开、阵列分组 | 分组依据、数量和归属清楚 |
| 比较／替换 | 同位置匹配切换、局部形变、并列对照 | 比较基准、单位、对象身份稳定 |
| 从局部到规模 | 拉远揭示阵列、单元扩展为系统 | 同一单元成为整体的一部分，数量含义可核对 |
| 沿步骤推进 | 路径跟随、线条接力、逐项累计 | 上一步结果成为下一步输入 |
| 转折／失败／修正 | 明确停顿、方向改变、局部颜色变化 | 触发原因与结果；故障效果绑定实际故障主题 |
| 结论／情绪停留 | 动作收束、稳定构图、简单切镜 | 完整结果与充分读时 |

相机移动分别说明发现、跟随或尺度作用；需要稳定坐标和证据阅读时使用静镜。快摇、隧道、全屏形变与闪切适用于有明确表达收益的段落。装饰动作保持次级权重，并在主信息进入时收束。具体镜头执行见[电影化运镜](cinematography.md)。

虚构例：讲解“将六份资料按用途分成两组”时，先建立六张带身份标签的卡片，依次标出分类依据，再移动到两列，最后拉远展示全貌并停留。卡片身份和总数贯穿变化，黄色指向当前处理对象。kinetic 可让分组边界扩展成下一镜的解释窗口；minimal 可保留两列构图，只更新当前对象和说明。每一步都能对应分类过程，转场继续发展同一问题。

## 跨风格应用

kinetic 与 minimal 的任务、动作强度及试排统一见[风格选择](styles.md#按任务选择表现方式)。新增风格明确色彩职责、动作幅度、并行密度、落定与阅读节奏；新增效果说明表达目的、接力线索和适用的物理或图形规则，并通过本文件的共用验收。

大字承担一个明确问题、名称、数字或结论。讲过程时优先展示对象和关系；口播段由旁白与字幕承载完整原句，文字主导段保留理解所需的引文、公式或推导。分步信息按语义逐项出现，最终数值、单位和最后一项全部落定后计算完整结果的读时。连续文字镜头逐段核对信息增量，把能由画面证明的内容改成动作或对照。`hero` 字号与 `holdMin` 是预设参数，实际字数、字号和读时按内容与手机画面验证。

为重点发现设计记忆点：先建立可理解的预期，再通过尺度、结构、因果或对照揭示结果，最后给出稳定画面。强动效前后安排较静段落；普通讲解段与高潮使用不同强度。节奏以理解与情绪发展为依据，重复微动按[防死帧](styles.md#防死帧)单独判断。

## 品牌色与现实约束

配色使用[品牌黄色彩系统](styles.md#品牌黄色彩系统)，先在本片主体上比较撞色与近似色的面积、背景、文字，再选一个有主题依据的方案。保持品牌色和变量颜色的职责；关键揭示可改变背景或面积，数据身份继续稳定。

按主体或图层标注写实、教学示意或抽象图形；同镜混用时分别说明各层的规则。写实的受力、接触、材质、尺度与空间关系按[现实物理与图形表达](motion-design.md#现实物理与图形表达)验证；示意画面标出必要的尺度、时间和机制简化。外部素材按[引用与复用](assets.md#外部资料的引用与复用)核对事实、权利和目标平台要求。

## 制作与审片闭环

在现有 events.md 记录每镜意义、转场接力和时序，重点段落填写语义转场表；review.md 绑定当前编码与实际观察。保持现有运行时字段，复杂形变由本片 src/ 和组件副本实现。

| 阶段 | 退出条件 |
|---|---|
| 分镜 | 每镜能回答三个问题；对象、动作、相机与转场有内容依据 |
| 完整粗剪 | 能复述主题和过程；快慢有层次；文字、换色和装饰的权重适当 |
| 重点样片 | 验证预备、峰值、落定、转场连续帧与一个普通段落；形变和真实物理各按其模型检查 |
| 当前编码 | 正常速度检查注意力与读时，360px 宽检查主体和文字，逐源核对素材用途和复用 |

音乐主导段在拍点之外补取动作峰值、最大变形、容器换字和切点两侧帧；按拍抽帧提供节奏定位，连续帧覆盖拍间变化。闭环段连续检查尾部接到开头的窗口，分别核对对象、相机、文字、指针与声音边界。

审片先检查事实、对象身份、可读性和因果，再检查连续性、节奏与表现力。工程测试、抽帧、连续观看和试听各自记录实际范围；创作结论以当前编码的观察为依据，详见[成片质量](quality.md)。
