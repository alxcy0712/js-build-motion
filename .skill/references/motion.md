# 动效语言与研究方法

## 创作主线

每镜回答主题、镜头意义、动作与运镜理由，再安排起始状态、触发、主动作、次级响应、落定、阅读与下一镜接力。主体、关系和证据承担解释，文字承担必要的问题、名称、标签与结论。同一时刻设一个主要注意目标，文字进入、主体峰值与相机加速按注意力交接错开。

先写观众应理解、感到或采取的行动，指定首要目标、可见事件与取舍。解释片核对因果与变量；产品片让操作证明能力；情绪片核对世界规则与情感推进。用同一对象、任务或空间贯穿输入、变化和结果，形成内容相关的视觉母题。重点发现与普通段落有强弱层次，完整结果形成后保留读时。

个人风格固定，表现方式按内容设计。品牌黄、变量身份、字体和包装沿用[个人识别](style-and-identity.md)，主体、场景、材质与轨迹由本片独立设计。写实、教学示意、抽象图形分别标明模型和简化；事实、来源与采用权利按[工作流](workflow.md)核对。

制作顺序：创作选择 → 状态与镜头编排 → 完整动态粗剪 → 正式素材重点样片 → 主片 → 当前编码审片。完整粗剪检查构图和快慢，样片检查复杂主体与中间态，编码主片检查最终视觉与声音。已认可的选择和明确委托持续沿用。

Kinetic 用于创作生动、有趣、具有视觉张力的视频。主动探索与主题相关的视觉隐喻、角色表演、物体互动、形态变化、空间变化和镜头接力，在组件框架与本片代码中实现最有表现力的方案。动作可经历起势、发展、接触、回弹与落定；速度、幅度、力度与尺度形成变化，主体、次级响应和相机相互配合。镜间可通过动作、对象、方向、形状、空间或视线接力，内容本身参与可观察的事件。运动、停顿、阅读与反应按本片排布，镜头数、转场数和动作强度由创意决定。

简单输入通常提供较大创作空间：模型补足叙事、隐喻、场景、镜头组织、时长和声音，选定有特点的方向推进；详细或天马行空的输入保留独特设想，精细处理镜内与镜间关系。表达方式可以主动构思，事实、数据、引用与原话沿真实证据。主题选择沿既有规则，影响正确性、范围或授权的重要缺口才追问。

Minimal 共用意义拆解：识别递进、转折、因果、重点与情绪，再用克制的构图、揭示、对照和停留推进。每个视觉事件按意义组织，一句话可产生多镜，几句话也可共享连续场景。

## 独立创作与项目表达

参考提供材料、时序、解释和诊断机制。本片独立选择故事、主体、视觉母题、构图、色板、镜头组合与声音，并记录设计依据。把自己的分镜与参考并排检查识别特征；整体表达过度依赖来源时，回到本片主张重设计关键段落。固定时长、BPM、循环、画幅和效果清单只在适用条件成立时采用。

先核对参考身份、版本、时长与实际观看范围。同一作品的成片和界面录屏关联为一组；全片联系表定位段落，关键转场按源帧率取连续帧，正常速度声画观看验证节奏。静帧支持构图与状态，运动曲线、声音同步和制作技术另需证据。原始提示词、站方改写、作者陈述、可见实现、代码实测与模型推断分别登记。互动量仅作为样本背景。

| 拆解项 | 本片记录 |
|---|---|
| 目的和状态 | 段落用途、台词主张、起点、触发、峰值、落定和阅读结束帧 |
| 形状和空间 | 轮廓、孔洞、语义地标、拓扑变化、景别、遮挡与焦点 |
| 运动 | 主体、相机和次层轨迹，启动差、接触、过冲与停止 |
| 接力 | 旧镜最后焦点、接力对象、遮挡时刻、新镜第一焦点与新增信息 |
| 色彩和文字 | 各色职责、面积、明暗、字级、完整读时 |
| 声音 | 实际听到的触发、重音、落定声与安静区间 |

记录“可见机制 → 适用任务 → 本片改写 → 验证方式”。公开作者、链接及归因统一存根 README；具体参考、时间码、素材、许可和实验留在本片。

## 解说动画方法卡

| 任务 | 对象、顺序与注意力 | 停留与验收 |
|---|---|---|
| 推导 | 固定变量身份与颜色；建立条件，逐步变换，揭示关系，返回结论 | 因果先后、必要条件、形变中间态可追踪；推导和结果分别可读 |
| 尺度揭示 | 熟悉单元 → 局部结构 → 同一单元成为整体；相机围绕稳定地标 | 比例和量尺有依据；近景揭示细节，全貌揭示规模 |
| 证据串联 | 原件 → 定位相关句/区域 → 关系标注 → 结论；来源保持可读 | 原话、日期、限定、作者和上下文准确；二次使用有新分析 |
| 步骤累计 | 上一步结果成为下一步输入，同画板累计，最后展示全貌 | 数量、归属、编号连续；最终清单从最后一项完成起计读时 |
| 关键词强调 | 主词显现 → 实测重音处峰值 → 回落可读 → 辅句补全 | 单一语义焦点，最大形变和最长文本通过边界检查 |
| 数据比较 | 建立坐标、基准与单位 → 数据进入 → 精确值落定 → 差异和限定 | 图形与数值共用状态；同尺度同条件；最终值、单位有完整读时 |

## 产品与体验叙事

将产品主张变成可见证明：输入、一次操作、反馈、完成态对应同一任务；速度与性能声明有可核对条件。熟悉尺度建立参照，细节与全貌互相接续。形变表达展开、分组、压缩等动词，匹配剪切连接功能与结果；固定产品比例、品牌地标与技术结构。

贯穿母题在开头、重点段和结尾发展；强动作后安排较静的证据与阅读段。快段以短词或单一事件为单位，长解释以实际语言、因果和读时决定镜长。相机移动说明发现、跟随或尺度作用，静镜提供坐标与证据阅读。关键接力可写“通过……，观众看见……”。

## 设计判断与有条件的方法

事实观察、来源解释、个人偏好和机制假设分栏记录。围绕一个具体问题研究参考，如“此转场怎样让观众追踪同一变量”；资料未覆盖的内容保留待验证。对关键收益尚不明确的形式选择，在现有预演中做同内容小对照，每次改变一个主要因素，保持事实、音源、时长、画幅和观看尺寸可比。

对照记录版本、变量、预期、观察与取舍；单次模型评分支持该次判断，用户偏好与受众反馈注明来源。工程正确、审美偏好、理解效果和传播结果分别验证；传播判断使用实际发布数据。出现反例时收窄或撤回方法，既有依据充分的选择直接推进。

可复用的研究请求：给定目的和参考，列出可定位观察、来源解释、偏好与假设，选一个最影响理解的问题，用当前内容设计对照和退出条件。创作请求：给定输入与事实、观众目标、视觉规则，写状态顺序、声音时点、制作路径与验收。复盘请求：从已授权的原文、代码和当前编码提取“现象 → 原因 → 修正 → 验证 → 归宿”，保留适用条件与未测范围。

## 连续取样与验证条件

参考拆解可产出联系表、切点候选、连续帧、热图、对象轨迹及声音时点。灰度差用于定位切点候选；阈值、去抖窗口、节拍网格结合原片核对，注明旧帧/新帧与实际时间。验证硬切、慢转场、大幅镜内运动、低运动与不同画幅；长片按窗口控制内存，声音拍点提供独立依据。

镜内运动、转场、背景纹理和相机分别解释。定格、步进、阅读与有意闪白按用途审查；细线、微小特征及确定性用原尺寸、冷启动/热缓存和乱序求帧复核。帧数按运行时实际取整策略登记，报告真实编码帧数与 N/fps 时长。诊断方法与当前覆盖见[布局与质量](layout-and-quality.md#连续帧诊断)。
