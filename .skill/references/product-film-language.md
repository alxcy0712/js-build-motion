# 产品与体验叙事

从观众应理解的能力或感受到的体验出发，将核心主张转为可见事件。按[创作问答](intake.md)选择表现方向，按[导演计划](direction.md)编排状态与镜头。

## 视觉证明

让一个完整动作证明一个主张：熟悉物件提供尺度，操作产生可辨认的结果，变量变化带来对应后果。保持比较条件、产品比例与事实口径一致，给结果留出稳定构图和阅读时间。演示、示意与真实运行按实际依据标注。

## 尺度与空间揭示

从局部到全貌时指定身份地标、起止景别、主体占比和停留；沿表面移动时写清要揭示的厚度、材质或部件。物体旋转展示表面，相机位移改变观察位置，光线变化揭示材质。按素材可支持的视角设计，真实环绕使用经过验证的三维几何或多视角素材。具体控制见[电影化运镜](cinematography.md)。

## 可追踪的镜头接力

逐镜写出前镜尾态、接力地标与后镜首态。轮廓、位置、尺度、运动方向、遮挡物、颜色或功能结果都可承担连接：圆形部件接功能局部，矩形框接下一场空间，操作接界面状态。按内容选择硬切、动作匹配、遮挡揭幕或形变，核对切点两侧的身份与注意力方向。

## 动作承托含义

文字重组表达重构，覆盖层抬起解释层次，部件展开揭示连接。安排预备、推进、落定与阅读，主次对象错时进入。技术结构按[精确几何](reference-geometry.md)核验，形变与受力按[动效设计](motion-design.md)检查中间态；材料隐喻在项目中注明表达口径。

## 快慢节奏与贯穿母题

短信息适合快速段，核心证明、复杂结构与情绪释放需要停留。重点动作前建立期待，完成后给稳定构图；时序由实测配音、目标语言和画幅确定，声音触发与可见事件对齐。

选一个与内容相关的轮廓、物件、色彩或空间规则，在开头、重点段落与结尾形成有意义的变化。母题维持身份，变化推进叙事；材质、光线、字体、运镜和声音围绕同一视觉约定展开。

## 按表达目标选择方法

| 表达目标 | 镜头结构 | 优先验证 |
|---|---|---|
| 材料或设计 | 细节发现 → 能力证明 → 全貌揭示 | 比例、材质、尺度参照与最终构图 |
| 软件能力 | 输入 → 处理 → 验证 → 成果 | 输入结果可追踪、焦点交接与演示口径 |
| 科学或工程过程 | 概览 → 局部变化 → 回到全貌 | 稳定地标、因果顺序、材料分层与读时 |
| 人物体验 | 日常 → 环境回应 → 情绪落点 | 世界规则、主体受力、动作完成与声音气质 |

先用完整动态粗剪检查信息推进与节奏，再用代表性短样片验证复杂主体、主要运镜和关键转场。核对动作开始、中间、极值、落定及切点两侧，连续播放检查运动和声音；最终结论绑定当前编码主片。来源采用与观察范围按[原作研究](story-mechanisms.md)保存在本片。
