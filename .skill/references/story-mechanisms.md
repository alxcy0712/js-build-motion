# 表达机制与原作研究

比较叙事方向或学习用户参考时读取。依据受众应理解、相信或感受到的变化选择机制，将采用点写入本片关键事件。题材提供推导线索，结构随本片内容与用户选择调整。

| 题材 | 叙事机制 | 可见事件示例 | 验收依据 |
|---|---|---|---|
| 硬件产品 | 一个使用条件中的能力证明，细节到全貌的尺度揭示 | 同一场景改变光圈，画面中景深随之改变，回到产品全貌 | 控制变量、型号与事实口径、比例、前后结果、实测声画对应 |
| AI 软件 | 一个具体任务贯穿输入、执行、验证和成果 | 原始表格进入分析，异常行被定位，结果经核对后成为可用报告 | 输入与结果可追踪，实际运行证据或演示口径，验证内容可辨认 |
| 品牌情绪 | 一条贯穿体验的世界规则，铺垫、升级与释放 | 人物动作使空间回应，重复的回应逐步改变情绪，结尾完成释放 | 母题与规则的一致性、情绪变化、动作落定和声音气质 |
| 大众科学 | 稳定视觉编码中的变量与因果变化 | 同一剖面中风力改变，暖水移动，降雨位置随后变化 | 方位与变量身份、因果先后、示意限定、连续状态与观众可复述的关系 |
| 工业技术 | 工序使材料、连接或功能发生可见变化 | 沟槽形成、材料填入、表面整平，最后建立可辨认的连接 | 独立技术依据、工序前后、材料边界、尺度接力与编码后的细节 |

声音围绕主事件安排：实测语义词、动作触发、完成提示和有用途的安静停留各有时间。验证界面、对比图和音效按实际任务填写；演示、示意与真实运行的口径写清。实际产品或运行结果尚未核验时，用观众可见的“流程示意”“示例数据”等标注相应范围，将演示结果和真实运行证据分别登记。广告可聚焦一个成果，完整解释可沿多个必要工序展开。

## 从原作到本片

本片evidence/reference-study.md保存来源、版本、实际读取或观看范围、可定位事件、采用机制、实现假设及验证。原作观察与本片设计推断分别填写；离散帧用于构图和形状，连续观看用于时序和节奏，实际试听用于声音。随后用主片将采用点落实到evidence/events.md。

## 规则的迁移与验证

把参考规则写成可检验的机制：状态决定镜头内容，注意力交接决定各层时序，材质与几何限定形变，受力与空间关系决定光影，内容与声音共同确定触发和停留。

采用前核对规则的适用条件。科学坐标强调变量稳定，产品展示强调比例与材质，解释段落强调读时，音乐主导段落强调节拍。风格、事件频率、帧率、响度、评分与迭代轮数由表达目标和交付条件确定。代码参考中的公式、阻尼区间、节拍相位与循环接缝通过独立检查后采用；模型比较与传播效果按相应证据判断。

将采用机制与成功条件落实为[导演计划](direction.md)的关键事件，用[动效设计](motion-design.md)实现连续变化，按[音视频排程](execution.md)核对实际时点，再由[成片质量](quality.md)复核当前编码。三维、替代渲染器或复杂转场用于解决可定位的表达缺口，比较同一事件的效果与成本后决定。

## 解说动画方法卡

按观众需要理解的关系选卡，同一镜头可以依次使用两张卡。把卡中的对象、动作与完成状态填写到本片 events.md，沿用现有导演计划和固定时间求帧契约。色彩、轮廓、位置或编号至少保留一种稳定身份线索；每个阶段只有一个主焦点。首次显现、强调峰值、动作完成与完整读时统一按[语义事件排程](captions-and-shots.md#中文语义事件排程)核对。

### 推导

| 项目 | 方法 |
|---|---|
| 适用任务 | 解释一个输入或变量怎样改变结果；先核实因果与控制条件 |
| 对象身份 | 同一输入贯穿处理与结果，变量固定颜色、符号和单位；新增量明确引入 |
| 动作顺序 | 建立初态与基准 → 改变一个变量 → 让影响沿关系传播 → 落定结果并回看条件 |
| 注意力 | 台词说到变量时局部强调，传播时跟随主变化，结果时保留输入与输出的对应 |
| 停留 | 动作完成后展示结果和成立条件；读时覆盖结论及单位 |
| 验收 | 观众能指出改变了什么、影响如何传到结果；中间态保留身份，因果先后与技术依据一致 |

### 尺度揭示

| 项目 | 方法 |
|---|---|
| 适用任务 | 揭示内部结构、局部与整体、数量级或空间关系 |
| 对象身份 | 世界坐标和尺度参照固定，至少一个地标贯穿起止构图 |
| 动作顺序 | 建立全貌与参照 → 靠近或穿行到新关系 → 稳定细节 → 拉回或并置全貌 |
| 注意力 | 相机围绕要揭示的关系运动，标签在对应结构稳定后进入；字幕固定在屏幕阅读区 |
| 停留 | 在细节到位后读标签，在全貌恢复后读比例或关系；运镜阶段另核对速度 |
| 验收 | 起止构图有信息增量，地标可追踪；比例、遮挡、方向与镜头运动一致 |

### 证据串联

| 项目 | 方法 |
|---|---|
| 适用任务 | 用档案、测量、运行记录或对照材料支持一个明确主张 |
| 对象身份 | 每份证据保留来源编号、范围与限定口径，真实材料按本片授权使用 |
| 动作顺序 | 提出待核对主张 → 展示证据全貌 → 框选关键内容 → 连到对应主张 → 汇合结论 |
| 注意力 | 一次框选一处，连线连接具体内容与论点；关键内容保持足够原尺寸可读区域 |
| 停留 | 从框选和必要放大完成开始读关键原文，汇合后给结论及限定条件读时 |
| 验收 | 每条主张都有可定位证据；裁框保留上下文，文字与单位完整，演示范围与事实范围一致 |

### 步骤累计

| 项目 | 方法 |
|---|---|
| 适用任务 | 解释工序、清单、关系图或逐步论证 |
| 对象身份 | 同一画板或主体保留已完成状态，步骤编号与材料身份持续可辨 |
| 动作顺序 | 建立起点 → 当前步骤改变主体 → 保留结果并引入下一步 → 最后回看完整结构 |
| 注意力 | 当前项获得强调，已完成项降低权重并保留关系；结构拥挤时按意义移动相机 |
| 停留 | 每步有局部落定；完整清单读时从最后一项呈现完成开始计时 |
| 验收 | 累计结构能解释先后与依赖；最后一项和全貌均有完整读时，主体仍可追踪 |

### 关键词强调

| 项目 | 方法 |
|---|---|
| 适用任务 | 突出阶段、动作动词、核心词或情绪落点 |
| 对象身份 | 主词保持原文字词和稳定位置；辅句、单位、限定语按层级进入 |
| 动作顺序 | 主词首次显现 → 在实测重音处达到强调峰值 → 回落到可读状态 → 辅句完成含义 |
| 注意力 | 同时只强调一个语义焦点；字号、位移或颜色任选必要手段，轮廓和安全区可复核 |
| 停留 | 强调动作完成后读主词与辅句；词级高亮和主词动作共用原词表 |
| 验收 | 峰值对应指定语义词，快动作后文字稳定可读；最长文本、最大形变与边界通过检查 |

### 数据比较

| 项目 | 方法 |
|---|---|
| 适用任务 | 展示量、趋势、差值或条件相同的前后结果 |
| 对象身份 | 比较对象固定编码，坐标、基准、单位与统计口径持续可见 |
| 动作顺序 | 建立坐标和条件 → 逐一引入数据 → 在相应台词处落定精确值 → 标注差异与限定 |
| 注意力 | 数据变化时聚焦当前系列，比较时同时保留共同基准；相机缩放同步维护量尺 |
| 停留 | 从最终数值落定开始读数，再给差异与条件独立读时；数值动画的中间值标为过程 |
| 验收 | 最终值由独立数据核对，轴和量尺一致；比较条件清楚，最终数值及单位有读时 |
