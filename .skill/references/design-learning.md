# 设计判断与参考学习

在创作方向含糊、需要学习新参考、重要形式选择存在分歧，或用户要求复盘更新 skill 时使用。已有方法足够时直接沿用；局部修改按影响范围复核。研究深度由当前决策需要确定，退出条件是能够作出有依据的选择，并明确剩余假设。

## 先约定要发生的体验

用一句话连接“谁在什么情境观看 → 应理解、感到或愿意做什么 → 哪个声画事件支持它”。从真实素材、声音、设备、时长和工具能力出发，选择本片最重要的体验与取舍，写入 NOTES.md，并在 events.md 引用；可观察结果进入 brief.acceptance。

| 主要任务 | 优先判断 | 具体观察 |
|---|---|---|
| 解释与教学 | 关系准确、过程可追踪 | 观众能指出变化原因；对象、基准和结果有连续证据 |
| 产品与广告 | 主张、证明与识别相互支持 | 重点动作证明承诺；观看后能将能力与产品对应 |
| 情绪与叙事 | 选择、关系和情绪变化成立 | 动作、空间、声音与停顿支持预期感受；含蓄段保留理解余地 |

混合任务注明当前段落的优先目标。事实、主体身份和必要文字的可读性沿用共用检查；理解、记忆、情绪和行动分别评价。取舍可写成“这一段优先让人看清两次结果，镜头保持稳定；下一段通过尺度变化建立惊喜”。

把“高级、克制、电影感”等感受词转成可比较的关系：主体占比、留白用途、文字层级、明暗与邻色、动作强弱、空间距离、声音进退。个人风格通过这些反复出现且有作用范围的选择积累。空白可用于分组和聚焦，安静可用于反应和回味，重复可建立预期；各自说明本片的用途和验证点。

## 围绕一个问题研究参考

先写下当前难以决定的问题，例如“结果出现后，怎样留出理解时间”。从仓库根 README.md 的“设计学习来源”及已有致谢中按问题选取原作、创作者说明、典藏资料或课程练习；聚合站提供发现线索，再追溯原始来源。获得足以试排的机制和边界后进入实验。

需要比较时，选择解决相近问题、形式有实质差异的参考，或能暴露方法边界的反例。作品声望支持选样，效果判断绑定当前任务和观察证据。古典概念的当代应用注明自己的转译；跨媒介迁移先核对观看进度由谁控制、能否回看，以及声音和交互条件，再重排显现与停留。

在本片 NOTES.md 或 evidence/ 中记录以下内容；独立维护的原始资料与过程按[核心维护](maintenance.md#内容边界与研究收敛)归档。

| 记录 | 内容 |
|---|---|
| 来源身份与范围 | 作者职责、作品版本、URL、核对日期、实际查看页面／帧／片段与试听范围 |
| 可见事实 | 具体对象、位置、先后、持续时间和声画变化；只按实际观察定位时间码 |
| 来源解释 | 作者或机构的原意与出处；引文和自己的释义分别标明 |
| 个人偏好 | 用户明确喜欢的关系、原话位置、适用题材与范围 |
| 机制假设 | 该选择可能怎样影响注意、理解或情绪；另一种合理解释及可能失效的条件 |
| 本片迁移 | 用自己的对象、构图与声音实现什么变化，在哪个事件上验证 |

参考逐帧与声音拆解复用[逐步拆解参考](motion-language.md#逐步拆解参考)，素材复用执行[素材选择](assets.md)。文章、静帧、连续画面和实际试听分别支持对应结论。将网页阅读记录为资料研究；全片观看、交互测试与受众反馈记录实际完成范围。

## 用小对照检验形式选择

当关键选择的收益尚待判断时，在已有[动态预演](direction.md#两级动态预演)中选一个能代表问题的片段。先写预期差异，再做同内容的 A/B 或删除实验。保持事实、对象、素材完成度和观看条件可比，主要改变一个待判断因素；时长或声音本身是变量时，记录其变化。多项因素共同变化的结果，归因保留在整体方案层面。

| 要判断的作用 | 可做的最小对照 | 观察与边界 |
|---|---|---|
| 构图与留白 | 同一内容改变主体尺度或间距 | 第一焦点、分组和完整结果是否清楚；保留必要标签 |
| 色彩层级 | 固定主色，改变背景或相邻色 | 主次、变量身份与文字可读性；灰阶检查辅助判断明暗层级 |
| 运动与转场 | 同一事件比较连续接力和简单切镜 | 是否更容易追踪对象和变化；保留足够的结果停留 |
| 声音与停顿 | 保留必要对白，比较配乐、环境声或停顿的作用 | 理解与情绪分别记录；声音承担的叙事信息纳入观察 |

删除实验用来辨认某一层的贡献。标题遮蔽等既有检查见[成片质量](quality.md#创作检查与预演退出条件)；当声音或文字承担核心表达时，以完整声画作为成片评价依据。

记录版本／时间范围、改变的因素、预期、实际观察、取舍和未决项。实际观看者参与时，先请其自由描述记住的内容、困惑点或感受，再说明设计意图；保留原话与观看条件。模型评审注明模型观察；受众理解、用户偏好和传播表现各自需要相应证据。

选择依据是本片优先目标获得了什么、付出了什么。收益相近时，优先采用制作和观看负担更小的方案；审美分歧说明观察依据与取舍。结果进入本片设计记录，并沿既有审批要求确定采用版本。

## 把经验变成有条件的方法

每条候选方法用以下字段收敛，具体证据保留在本片或维护归档；共享层保存通用机制和独立可执行的验证方法。

> 情境与目标 → 机制假设 → 操作 → 适用边界／反例 → 验证方法 → 当前支持范围

虚构例：解释多层结构时，保留一个位置地标，让观众追踪局部与整体。可比较“连续拉远”和“同位置切换”，观察位置关系与阅读成本。单步操作可能更适合直接呈现结果；方法先作为待验证候选。

| 知识状态 | 可以形成的结论 | 后续处理 |
|---|---|---|
| 待验证 | 参考观察或机制假设 | 在相关本片按需试排，记录可能推翻它的现象 |
| 局部支持 | 在已记录版本和条件下观察到收益 | 保存成立条件与反例，换题材时重新判断 |
| 跨情境支持 | 在具有实质差异的内容或观看条件下得到支持 | 按维护授权提炼通用方法，保留支持范围 |
| 已收窄或撤回 | 新证据限制了原先解释 | 更新权威规则和调用，历史依据留在归档 |

这些是知识记录用语，沿用现有 NOTES.md／evidence/，保持运行时状态契约不变。一次喜欢进入有范围的偏好，一次成功进入案例；skill 的 learned 表示该轮维护已吸收证据，方法有效性按上表单独记录。明确的用户约束和工程正确性要求各按原有依据执行。

## 可复用提示词

按当前任务选用一段，并填入已知内容；已有选择和授权持续沿用。

**研究一个参考**

```text
围绕当前影片的[具体问题]研究[参考]。先检查已有方法与用户选择，记录来源版本和实际观察范围。分开写可见事实、来源解释、个人偏好和机制假设；比较一个形式不同的解法或边界情境。提炼最有用的条件化方法，用本片对象改写，并给出能检验收益的小对照。把来源与观察保存到本片，公共来源归因沿用根 README。
```

**作出创作选择**

```text
依据本片目的、受众和真实素材，写清希望发生的体验、首要判断和取舍。把[感受词]转成构图、色彩、运动与声音的具体关系。沿用已选主题；方向尚待选择时比较有实质差异的方案并推荐。仅在关键收益尚待判断时，把小对照纳入已有动态粗剪；按实际证据报告选用理由。
```

**复盘并更新方法**

```text
在我指定的项目与维护范围内，对照创作意图、当前版本、实际反馈和实验记录。分别提取偏好、可见结果与机制假设，给候选方法注明适用边界、反例、验证方法和支持范围。合并到已有权威主题，具体过程留在项目；按核心维护流程备份、验证并 seal，报告本轮改动与仍待实践检验的部分。
```
