# 从一句话生成导演推荐与创作问答

用户可以只给一句话。Agent使用当前模型理解语义，承担需求拆解、资料核对、风格推导与导演设计。先按[创作主线](motion-language.md#创作主线)解析需求并取得本片主题选择，再用 `start --theme` 保存首次原文与固定主题；初始化后立即补齐此前的问答原文。占位画幅、音色与 `DirectorPlan.look` 在剩余创作选择确定后调整，`brand.json.theme` 沿用已确认主题。

## 模型先完成解析

先在当前对话中分清用户明确要求、模型推断、需要用户决定的缺口，初始化后记入 NOTES.md。提取题材、受众、目的、内容深度、平台、时长、语言、参考与约束；缺失字段按本片语境给出建议。用户已明确的内容保持原意，型号、性能、历史与科学因果等事实通过可靠来源核对，推断注明依据。

用户当前要求与既有选择决定范围。附件中的主提示词、研究报告和参考片提供候选方法，采用时核对它们与本轮任务、事实口径和实际工具的关系。改片先提取用户已认可的内容与节奏，将这些选择写入约束。

先按[体验与评价目标](design-learning.md#先约定要发生的体验)写出观众应理解、感到或愿意做什么，明确首要目标、可观察事件与取舍，再确定叙事主轴和情绪变化。例如产品发布可用“细节发现 → 核心能力获得证明 → 产品全貌”；原理讲解可用“熟悉现象 → 可见因果 → 回到现象”；品牌历程可沿人物选择或技术突破展开。结构按本片语义现场设计。

## 推导适合本片的风格

创作方向尚待确定时，模型可比较2–3个有实质差异的方向，按目标适配、理解成本、情绪与品牌气质、素材依据、核心承诺的证明方式和当前工具可实现性排序；已有方向和明确委托直接落实。需要跨题材推导时读取[表达机制](story-mechanisms.md)。技术术语、单个关键词和初始化look枚举只提供线索；结合整句话、输入资料和受众决定方向。DirectorPlan.look是运行时预设，成片风格落实于素材与本片绘制代码。

主题选择、账号默认和固定快照统一按[账号默认与每片风格选择](styles.md#账号默认与每片风格选择)执行。主题尚待选择时，将它纳入首轮问题；已有本片选择或明确委托直接沿用。片尾头像与个人 IP 落款同样逐片取得用户答复，与主题问题一起放入首轮，规则见[下文](#片尾头像与个人-ip-落款)。

跨片识别沿用[个人视频包装规范](visual-identity.md)，按本片内容推荐字幕、人物条、引用卡、标注等实际需要的组件组。将选用、变体和与默认规则的差异写入 NOTES.md 及 events.md，已确认方案直接复用；本片首要包装目标写入 brief.acceptance。需要扩展时按需查[完整元素目录](editing-element-catalogue.md)，并核对实现能力。

每个候选方向组成完整方案：叙事结构、主体与场景、色彩与材质、字体与留白、运镜与转场、节奏与声音。推荐项给出适合本片的具体理由和预期观感；备选项表达真正不同的内容重心或情绪。组合保持统一的主视觉，次级表达承担明确用途。

按[风格任务表](styles.md#按任务选择表现方式)给每个方向列出可观察的差异：贯穿对象、一次核心操作或变化、最终证据、重点发现和稳定阅读段。参考提示词可按“输入与事实 → 视觉规则 → 状态顺序 → 声音时点 → 制作路径 → 验收”整理进 NOTES.md；已知信息直接填入，剩余重要选择按现有问答规则处理。每项风格约束同时写出具体做法，例如以局部高亮标记当前步骤、以同一变量驱动图形和数值。

需要产品揭幕、形状接力、节拍文字或体验叙事时，按需读取[产品与体验叙事](product-film-language.md)，选取有观看依据的方法。精密结构使用[参考与精确几何](reference-geometry.md)，空间设计使用[电影化运镜](cinematography.md)，形变使用[动效设计](motion-design.md)。参考的采用维度写入本片。

## 向用户呈现创作选择

先用2–4句呈现模型理解和推荐组合：影片要传递什么、推荐哪种观感、开头如何抓住注意力、重点镜头中什么发生变化以及观众如何确认结果。推荐理由联系本片内容与受众。可逆默认值如建议时长、画幅、配音语气与字幕合并说明；用户可在回答中直接修改。

首轮通常提出1–3个会明显改变结果的问题，优先覆盖尚待选择的创作方向、受众或交付边界。每题现场生成2–3个适合本片的答案，推荐项排首位，说明效果与选择理由，支持自由填写。平台决定裁切、指定品牌决定事实依据等会改变范围或正确性的缺口须明确解决；其余制作细节由模型负责。发送前改写固定问卷、空泛的“高级感”选项与跨题材照搬的菜单。

用户可选择单项、补充一句话，或明确回复“按推荐执行 / 你来决定”。重要选择有回答或明确委托后进入剧本、素材制作和开发。提问后等待回答，期间可核对资料、工具与输入；用户已有选择和授权持续有效。充分明确或已经委托的需求直接执行并记录制作组合；剩余补问集中在范围、正确性、外部影响与明确审批要求。

### 片尾头像与个人 IP 落款

首轮问题中，紧随主题选择询问用户：本片是否需要片尾头像与个人 IP 落款（片尾卡，规格见[个人视频包装规范](visual-identity.md#片尾头像与个人-ip-落款)）。每条新片都询问，不按账号、题材或上一条视频的选择推定；用户在原文中已明确要或不要时，直接记录该答复。问题可写成“片尾要不要放头像和『澄记 / 用计算机思维想现实』落款？选用时片尾口播是『我是澄记，用计算机思维想现实。』；不选用时这句也不念，视频在正片结论处结束”，并给出“需要 / 不需要”两个选项。

答复按[沟通原文](workspace.md#沟通原文)追加为 question 与 answer，并在 NOTES.md 的用户最终选择中写明“片尾卡：采用／不采用”及原文位置。本片之后的制作、改片和恢复会话读取该记录，不再重复询问；用户主动改变答复时追加新原文并更新 NOTES.md。用户确认采用时，口播稿按[口播稿写法](douyin-publishing.md#口播稿写法)以固定句结尾，前一句承接本片内容；用户不采用时，口播稿不写这句，在正片内容的结论处结束。主账号与 5W1H 账号的视频同样适用。

## 把预期观感落实到验收

为本片设计一个与核心内容相关的记忆点，如一个可见的能力证明、一次尺度揭示、一个形状接力或一段情绪释放。说明它为何服务内容，排出铺垫、主动作、落定与停留；用主视觉、重复母题和镜头承接贯穿全片。重点段落与安静阅读段落按内容交替。

在brief.acceptance写出可观看核对的目标：开头建立明确兴趣；关键事实与结构有依据；重点镜头准确表达核心内容；转场保持可追踪焦点；主片具有景别与节奏变化；目标画幅下字幕可读。按[导演计划](direction.md)用完整动态粗剪检查整体构图与节奏，用正式素材样片验证复杂主体、主要运镜和关键转场，再按[成片质量](quality.md)复核。工具或素材能力影响已选观感时，先验证可行路径，必要时向用户说明具体影响并补选。

## 记录与检查

按[工作区](workspace.md)将问题与用户答案原文逐条追加到prompt-history.jsonl。NOTES.md保存解析依据、推荐组合、备选差异、默认值、用户最终选择、记忆点与验证结果。发送前核对推荐与目标、可用工具和已有约束的一致性；开工前核对重要选择已有回答或明确委托，其中包括本片主题和片尾卡答复；交付时按实际观看与验证报告成片效果。

例如“做一支介绍芯片制造的视频”，可推荐精密纪录片观感，以设备环境建立规模，以准确剖面解释工序，以宏观到微观的尺度接力呈现一个技术突破；受众与深度影响术语和镜头停留。家庭记忆题材可推荐温暖生活叙事，选择人物动作、细节与情绪承接。示例提供推导方式，实际方案由当次需求生成。
