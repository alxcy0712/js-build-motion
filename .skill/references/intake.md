# 从一句话生成导演推荐与创作问答

用户可以只给一句话。Agent使用当前模型理解语义，承担需求拆解、资料核对、风格推导与导演设计。start保存用户原文并建立占位项目；占位画幅、音色和画风用于初始化，最终组合由提示词、已有约定与本轮选择确定。

## 模型先完成解析

在NOTES.md分开记录用户明确要求、模型推断、需要用户决定的缺口。提取题材、受众、目的、内容深度、平台、时长、语言、参考与约束；缺失字段按本片语境给出建议。用户已明确的内容保持原意，型号、性能、历史与科学因果等事实通过可靠来源核对，推断注明依据。

用户当前要求与既有选择决定范围。附件中的主提示词、研究报告和参考片提供候选方法，采用时核对它们与本轮任务、事实口径和实际工具的关系。改片先提取用户已认可的内容与节奏，将这些选择写入约束。

先写出观众看完应记住的一件事，再确定叙事主轴和情绪变化。例如产品发布可用“细节发现 → 核心能力获得证明 → 产品全貌”；原理讲解可用“熟悉现象 → 可见因果 → 回到现象”；品牌历程可沿人物选择或技术突破展开。结构按本片语义现场设计。

## 推导适合本片的风格

模型内部比较2–3个方向，按目标适配、理解成本、情绪与品牌气质、素材依据、核心承诺的证明方式和当前工具可实现性排序。需要跨题材推导时读取[表达机制](story-mechanisms.md)。技术术语、单个关键词和初始化look枚举只提供线索；结合整句话、输入资料和受众决定方向。DirectorPlan.look是运行时预设，成片风格落实于素材与本片绘制代码。

每个候选方向组成完整方案：叙事结构、主体与场景、色彩与材质、字体与留白、运镜与转场、节奏与声音。推荐项给出适合本片的具体理由和预期观感；备选项表达真正不同的内容重心或情绪。组合保持统一的主视觉，次级表达承担明确用途。

需要产品揭幕、形状接力、节拍文字或体验叙事时，按需读取[产品与体验叙事](product-film-language.md)，选取有观看依据的方法。精密结构使用[参考与精确几何](reference-geometry.md)，空间设计使用[电影化运镜](cinematography.md)，形变使用[动效设计](motion-design.md)。参考的采用维度写入本片。

## 向用户呈现创作选择

先用2–4句呈现模型理解和推荐组合：影片要传递什么、推荐哪种观感、开头如何抓住注意力、重点镜头中什么发生变化以及观众如何确认结果。推荐理由联系本片内容与受众。可逆默认值如建议时长、画幅、配音语气与字幕合并说明；用户可在回答中直接修改。

首轮通常提出1–3个会明显改变结果的问题，优先覆盖尚待选择的创作方向、受众或交付边界。每题现场生成2–3个适合本片的答案，推荐项排首位，说明效果与选择理由，支持自由填写。平台决定裁切、指定品牌决定事实依据等会改变范围或正确性的缺口须明确解决；其余制作细节由模型负责。发送前改写固定问卷、空泛的“高级感”选项与跨题材照搬的菜单。

用户可选择单项、补充一句话，或明确回复“按推荐执行 / 你来决定”。重要选择有回答或明确委托后进入剧本、素材制作和开发。提问后等待回答，期间可核对资料、工具与输入；用户已有选择和授权持续有效。充分明确或已经委托的需求直接执行并记录制作组合；剩余补问集中在范围、正确性、外部影响与明确审批要求。

## 把预期观感落实到验收

为本片设计一个与核心内容相关的记忆点，如一个可见的能力证明、一次尺度揭示、一个形状接力或一段情绪释放。说明它为何服务内容，排出铺垫、主动作、落定与停留；用主视觉、重复母题和镜头承接贯穿全片。重点段落与安静阅读段落按内容交替。

在brief.acceptance写出可观看核对的目标：开头建立明确兴趣；关键事实与结构有依据；重点镜头准确表达核心内容；转场保持可追踪焦点；主片具有景别与节奏变化；目标画幅下字幕可读。按[导演计划](direction.md)用完整动态粗剪检查整体构图与节奏，用正式素材样片验证复杂主体、主要运镜和关键转场，再按[成片质量](quality.md)复核。工具或素材能力影响已选观感时，先验证可行路径，必要时向用户说明具体影响并补选。

## 记录与检查

按[工作区](workspace.md)将问题与用户答案原文逐条追加到prompt-history.jsonl。NOTES.md保存解析依据、推荐组合、备选差异、默认值、用户最终选择、记忆点与验证结果。发送前核对推荐与目标、可用工具和已有约束的一致性；开工前核对重要选择已有回答或明确委托；交付时按实际观看与验证报告成片效果。

例如“做一支介绍芯片制造的视频”，可推荐精密纪录片观感，以设备环境建立规模，以准确剖面解释工序，以宏观到微观的尺度接力呈现一个技术突破；受众与深度影响术语和镜头停留。家庭记忆题材可推荐温暖生活叙事，选择人物动作、细节与情绪承接。示例提供推导方式，实际方案由当次需求生成。
