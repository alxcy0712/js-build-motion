# 导演计划

新片先完成[创作问答](intake.md)，沿用用户已明确的要求与创意委托。在 NOTES.md 写清观众应记住的一件事、主视觉、叙事主轴、材质与光线、字体和声音气质。重要视觉选择按已有审批要求处理。事实、素材与技术结构按[素材选择](assets.md)和[精确几何](reference-geometry.md)核对。

各类风格的动效段落按[共用动效标准](motion-language.md)设计。每镜先回答主题、台词／镜头意义、动作与运镜选择三个问题，再写观众应看见的证据；相邻镜头的接力须能说明信息或情绪作用。

## 从内容到连续状态

先为核心承诺设计“起始状态 → 触发 → 可见变化 → 结果”，再决定构图和文字。以同一对象、变量、任务或空间关系串起段落；把输入、选择、压缩、检验、失败、结果等动词落实到画面。标题承担提问、转折或结论，主要信息由事件发展呈现。把观众要读的内容和要看的动作排出先后。

在 evidence/events.md 的镜头编排表列出全部镜头，每行足够简短：

| 项目 | 需要明确的选择 |
|---|---|
| 时间与状态 | 台词或音乐时段、镜头意义、对象身份、起始状态、触发、结果与停留用途 |
| 构图变化 | 焦点、起止景别、主体占画面比例、空间关系、文字的进入与退出 |
| 运动分工 | 主体做什么、相机揭示什么、次层何时响应；刚性关联部分共享变换 |
| 前后接力 | 上一镜保留的对象、位置或方向；本镜结果怎样成为下一镜的起点；转场带来的理解或情绪收益 |
| 声音 | 实测语义词或音乐拍点、接触或完成声、安静的用途 |

把全片镜头并排比较，辨认持续重复的构图。连续三镜都沿用相同的标题区、中央卡片和页脚时，检查其叙事用途，并为需要推进的段落改写空间关系或主体状态。品牌统一通过颜色、字体、形状和运动语法保持；各镜按内容组织版面。技术讲解保留必要的坐标、标签和证据口径。

短促的宣传段可从每 2–4 秒一次有效信息变化试排，长讲解按因果、动作和阅读安排。有效变化包括关系被揭示、动作取得结果、尺度或焦点发生改变；背景粒子、循环漂浮和进度条计入氛围。静镜与长停留写清观众正在理解或感受什么。旁白、字幕和镜头各自分段，完整台词可以跨视觉切点，详见[语义分镜](captions-and-shots.md)。

## 两级动态预演

关键形式选择的收益尚待判断时，按[小对照](design-learning.md#用小对照检验形式选择)在现有预演中比较同内容的解法，记录变量、观察和取舍。已有明确依据的选择直接推进，局部改片沿用认可的整体结构。

1. **完整动态粗剪**：用低分辨率、简化几何和已测配音／音乐走完整时间轴，保留计划中的对象动作、相机与切点。正常速度检查开头、段落推进、构图变化、快慢和结尾。对重复布局、入场后长时间停滞、同款切法连续使用逐段写下具体修正，再展开精修。短片可直接使用整片预览。
2. **重点镜头样片**：用正式主体与素材验证最有代表性的动作、主要运镜和相邻切点，检查极值、中间态、字幕与声音。覆盖一个普通段落，检验常规镜头的质量。状态结果清楚、身份与结构成立、景别和接力可感知、文字可读、时序连续后进入主片。

样片与粗剪可按风险交替制作。已有认可的全片结构用于局部改片时，预演覆盖改动及相邻镜头。相机控制、焦点坐标和分层方法见[电影化运镜](cinematography.md)；受力、形变与连续目标见[动效设计](motion-design.md)。产品广告可按需研究[产品与体验叙事](product-film-language.md)，其他题材按[表达机制](story-mechanisms.md)选择。

## 关键事件与主片整合

承担核心承诺、机制解释或情绪转折的事件使用稳定 ID，记录内容依据、起始状态、主动作、结果和验收条件。观众应能看见或听见的证据写入 brief.acceptance；主片时间码关联实际编码。事件状态按 planned、sample-verified、integrated、encoded-verified 逐步更新，各状态保留其版本和观察范围。

先测真实配音的逐句与关键词时间，再定动作、镜长和阅读停留；音乐主导段按实测拍点或程序音乐的节拍原点排程。事件表使用同一绝对时间轴。每个重点事件的承诺与实际结果按[成片质量](quality.md)复核。

## 运行时字段

通过 capabilities --schema 查询 DirectorPlan@0.1 字段与枚举。idea 保留原文，purpose 写叙事作用，visualIntent 写具体可见变化。事件表承载导演设计；复杂轨迹由本片 src/ 实现。相机指定一处控制：使用本片相机时将该镜头的管线 cameraMove 设为 static，并省略该镜的 cameraPath。

voice 选择本片音色，narrationRate 为相对正常语速的整数百分比，narrationOffset 为镜内秒数；sfx 填写镜内 offset、preset 与可选 volume。sfx: [] 用于安静镜头，省略字段沿用既有默认值。click 与 success 按实际事件使用。

brief.json 保存交付、输入来源、工具、声明与验收；humanRounds 未知时填 null。导演项目修改 director.json 后运行 direct compile；原生 VideoSpec 使用 project.json 的 entry 和 drawing。后续按[绘制](drawing.md)与[音视频流程](execution.md)执行。
